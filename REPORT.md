# Задача Эрдёша — Сураньи №708. Совместное размещение составных делителей

25 ноября 2026. Рабочая исследовательская запись. Все новые верхние оценки равномерны по сдвигу. Доказательства математические, формализации Lean для них нет. Приоритет в литературе не установлен.

Пусть A — n различных чисел от 2 до M. В интервале I из M последовательных целых выбираются различные точки, произведение которых кратно произведению A. Минимум числа точек обозначен τ. Для g(n) берётся супремум при M=max A. Используем версию «не более». Если есть ноль, одной точки достаточно, отрицательный интервал отражается. В дальнейшем I положителен. В нём не меньше floor(M/d) кратных любого d. Полное произведение I кратно M! по формуле для биномиального коэффициента, а произведение A делит M!. Поэтому после размещения делителя P цели каждый оставшийся простой множитель можно добавить за одну точку. При нехватке показателя p имеется ещё не выбранное кратное p.

## 1. Ограниченное число произвольных составных делителей

**Теорема 1.** Пусть каждый модуль либо имеет не более двух простых множителей с кратностью, либо записан как dpr, где p≤r простые. Для каждого модуля достаточно одного выбранного представления. Если различных значений d≥2 не более k, то
$$\tau(A,I)\le 2n+C(k).$$
Константа не зависит ни от значений d, ни от числа, величины или кратностей их общих простых делителей. При фиксированном k это даёт требуемый асимптотический коэффициент. Если минимум floor(M/d) по используемым d достаточно велик в зависимости от k, имеем уже τ≤2n−1. При отсутствии таких d достаточно зарезервировать кратное одного модуля и добавить простые остальных.

**Лемма о запасе в условии Холла.** В любых L последовательных положительных числах J рассмотрим произвольное непустое семейство различных полупростых pr≤L, p≤r, с требованием назначить кратное p. Пусть T — размер семейства, N — число соседей. Тогда T/N→0 равномерно по семействам и сдвигам при L→∞. То же верно для каждого подсемейства. Кроме того N≥floor(√L).

Доказательство. Пусть S — множество реально используемых меньших простых, x=Σ1/p, D=Σ floor(L/p). Тогда D≥(1−1/√L)Lx. Обозначим числом u(b) количество p из S, делящих b. Сумма u(b) не меньше D, а сумма u(b)(u(b)−1) не больше 2Lx², поскольку при p,p′≤√L каждое попарное пересечение имеет размер не выше ceil(L/(pp′))≤2L/(pp′). Неравенство Коши и монотонность y²/(y+2Lx²) дают N≥D²/(D+2Lx²). В частности, для L≥4 имеем N≥D/5 при x≤1 и N≥L/12 при x≥1.

С одной стороны, T≤Σπ(floor(L/p))=o(D), так как все аргументы не меньше floor(√L) и π(y)/y→0. С другой стороны, число всех полупростых до L есть o(L). Действительно, при фиксированном z полупростых с множителем ≤z не больше Σ_{p≤z}π(L/p)=o_z(L), где последнее обозначает o(L) при фиксированном z. Остальные взаимно просты с W=∏_{p≤z}p, их не более Lφ(W)/W+O_z(1) по периодичности. Затем устремляем z к бесконечности, используя классическое произведение Эйлера ∏_{p≤z}(1−1/p)→0. Вместе эти две оценки доказывают лемму. Нижняя граница N следует из одного используемого p≤√L.

**Совместное назначение.** После запрещения h точек пусть в каждой из не более k групп до запрещения выполнялись N≥2kT и N≥2h для всех непустых подсемейств. В группе d работаем в L=floor(M/d) последовательных частных кратных d. Различность dpr даёт различные pr в группе. После возвращения к исходному интервалу и удаления запрещённых точек остаётся не меньше N/2≥kT соседей. Для объединения подсемейств по группам размер объединения соседей хотя бы максимум их количеств, то есть не меньше их суммы, делённой на k. Так проверено условие Холла для **всех** модулей совместно. Получаем различные точки, кратные своим dp. Остался один простой r на модуль. При достаточно больших L можно заранее взять одну точку для целого модуля, запретить её (h=1) и применить этот аргумент. Расход ≤2n−1.

**Малые группы.** Нужна равномерная грубая оценка F(m)=16m² для произвольных m≥1 модулей, F(0)=0. При M<(4m)² хватает всего I. Иначе положим K=4m, U=M/K≥√M. В каждом модуле простые >U оставим отдельными блоками, последовательные серии остальных жадно разбиваем на блоки произведения ≤U. Произведение двух соседних блоков больше U. Четыре блока невозможны, так как две непересекающиеся пары дали бы произведение >U²≥M. Блок ≤U имеет не менее K кратных и получает новую точку, большой простой исправляется простым шагом. Всего нужно не более 3m<K точек, что доказывает оценку.

При k≥1 выбираем конечную возрастающую последовательность целых H₀=1,…,H_{k+1}. После выбора H_i берём H_{i+1} таким большим, что для всех L≥H_{i+1} лемма гарантирует N≥2kT и N≥2F(kH_i). Среди k+1 непересекающихся промежутков [H_i,H_{i+1}) имеется хотя бы один без значений floor(M/d). Тогда группы с L<H_i содержат суммарно m≤kH_i модулей, поскольку pr≤L различны внутри группы. Покрываем сначала эти модули, резервируем h≤F(m) выбранных точек. В остальных группах L≥H_{i+1}; совместное назначение избегает резерва. Все модули ранга ≤2 добавляются простыми шагами. Цена ≤h+2(n−m)≤2n+F(kH_k). Это доказывает теорему без предположений о росте размеров отдельных групп. Оценка константы грубая и для численных задач не предназначена.

**Проверяемый вариант для растущего числа групп.** Если для каждой группы известна верхняя граница λ_d для отношения T/N′ по всем подсемействам, где N′ считает соседей после резерва, то достаточно Σλ_d≤1. Действительно, для любого объединённого подсемейства каждое N′_d≤N′_общ и ΣT_d≤(Σλ_d)N′_общ. Величины λ_d можно ограничивать через вторые моменты из леммы; пустые группы в сумме отсутствуют. Это достаточный критерий, не общая оценка при k→∞.

## 2. Произвольно много попарно взаимно простых составных делителей

**Теорема 2.** Сохраним представления из теоремы 1, но число d произвольно, а разные значения d попарно взаимно просты. Построим ориентированный граф со значениями d в вершинах. Для каждого модуля dpr проводим дугу из d в d′, если d′≠d и p делит d′. Такая вершина d′ не более чем одна. Дуги считаются с кратностью по модулям. Если удаление дуг f модулей уничтожает все ориентированные циклы, то τ≤2n−1+f. В частности, при отсутствии циклов получаем 2n−1, при f=o(n) получаем (2+o(1))n. Удобное достаточное условие ацикличности — p≤наименьшего простого делителя d для каждого модуля. Тогда при переходе к другому d′ его наименьший делитель ≤p, причём равенство минимумов двух разных d невозможно.

Доказательство. Резервируем кратное одного полного модуля. Для каждого d отдельно применяем первую лемму Холла из приложенного отчёта G3, допускающую запрет одной точки, в частных кратных d. После умножения на d получаем для каждого оставшегося dpr точку, кратную dp, причём для одного d точки различны. Аудит использованной леммы приведён ниже. Пусть в b встретились t назначений. Все их d_i различны, так что D=∏d_i делит b. Если некоторый p_i не делит ни одного чужого d_j в группе, то Dp_i делит b, поскольку d_i p_i делит b и все остальные d_j взаимно просты с d_i p_i. Тогда из t модулей осталось 2t−1 простых. Вместе с b они стоят ≤2t. Если для каждого i есть чужое d_j, делящееся на p_i, внутри группы каждая вершина имеет исходящую дугу, и есть ориентированный цикл. Здесь засчитываем D, расход ≤2t+1. Разные точки используют непересекающиеся наборы модулей, поэтому таких групп не более f. Сначала выбираем резерв и все различные b, затем вносим все остаточные простые. Это исключает повторное использование одного показателя и доказывает оценку.

**Семейство с большим штрафом за повторения.** Возьмём t≥2 малых простых p_i, t различных d_j, каждое из произведения s≥2 своих простых больше всех p_i, и t новых простых r_l больше всех p_i. Все три набора простых дизъюнктны. Пусть A состоит из всех p_i d_j r_l. Тогда n=t³, НОД семейства равен 1, каждый внутренний простой имеет r_p=t², и уже внутренние простые дают штраф st(t²−2). Отношение к n стремится к s при фиксированном s и не ограничено при растущем s,t. Между тем τ≤2n−1 при каждом сдвиге. Здесь растут и число делителей d, и, по желанию, число простых в каждом модуле. Это прямое опровержение идеи равномерно оценить сам штраф через o(n).

**Настоящий сбой локального рассуждения.** Допустимы назначения 6·5·11 и 35·2·3 в точку 210 в интервале [1,330]. Оба требования 6·5 и 35·2 выполнены, но ни 210·5, ни 210·2 не делит 210. Возникает цикл 6→35→6. Это препятствие для конкретных назначений; другой выбор представителей может его устранить.

## 3. Оценка для произвольного A через включения носителей

Для каждой непустой пары требований p,j (j≥1) положим S_{p,j}={a∈A : p^j делит a}; одинаковые непустые множества отождествляем. Для a∈A пусть w(a) — максимальное число попарно несравнимых по включению носителей, содержащих a.

**Теорема 3.** Для любого A и любого сдвига τ≤Σ_{a∈A}w(a). В частности, при сумме избытков Σ(w(a)−2)_+=o(n) выполнена целевая оценка. При ламинарном семействе носителей, то есть когда любые два из них вложены или не пересекаются, хватает n точек.

Доказательство. Обходим носители S по возрастанию размера. Положим d_S=НОД всех a∈S. Уже в [1,M] есть |S| различных кратных d_S, поэтому столько же или больше есть в I. Доводим число выбранных кратных d_S до |S|, добавляя только новые точки; пусть их h_S. В конце для каждого p^j имеется не менее |S_{p,j}| выбранных кратных, так как p^j делит соответствующий НОД. Сумма по j даёт нужный показатель p.

Каждую добавленную при S точку припишем одному модулю из S. Если h_S>0, все точки, добавленные при T⊊S, уже кратны d_S, поскольку d_S делит d_T. Они различны и вместе с h_S дают не более |S|. Поэтому можно выбрать h_S различных модулей из S, ещё не получавших начисления от строгих подмножеств S. В итоге носители, начислившие точки данному a, образуют антицепь. Суммирование даёт теорему. Глобально раскрашивать носители в цепочки не требуется.

**Граница применимости.** В трёхмерном семействе из §2 у каждого модуля ровно три несравнимых носителя (три координатных сечения). Теорема 3 даёт 3n, а теорема 2 даёт 2n−1. Ровно тот же разрыв есть уже при s=1. Свести общий вопрос к арифметически ничем не ограниченному утверждению «средняя ширина не больше двух» нельзя.

## 4. Ещё одно следствие запаса Холла

Пусть имеется конечный алфавит попарно взаимно простых целых u≥2. Каждый модуль — произведение не более трёх букв с повторениями. Тогда при достаточно большом M верно τ≤2n−1, равномерно даже по меняющемуся алфавиту.

Для тройки x≤y≤z выберем середину y внутренним делителем. В частных кратных y нужны представители различных пар xz≤L, кратные x. В лемме §1 попарные пересечения оцениваются так же по взаимной простоте букв. С каждой буквой связать один её простой делитель; выбранные простые все различны. Поэтому при фиксированном x число возможных z не выше π(floor(L/x)), а вообще число пар не превосходит числа полупростых до L по инъекции неупорядоченных пар букв в пары их выбранных простых. Доказательство T/N→0 сохраняется. Так как y≤√M, все L равномерно растут, запрет одной резервной точки допустим.

В группе из t назначений с различными серединами y_i число b делится на произведение этих середин и ещё на одну букву x_i: берём назначение с наименьшим y_i, тогда x_i≤y_i и x_i либо отсутствует среди всех середин, либо равно своей середине. Для составной буквы u ведём учёт по ord_u(b)=max{j:u^j делит b}. Требуемый суммарный показатель буквы равен числу её вхождений в исходные слова. Он доступен в полном интервале, поскольку на каждом уровне u^j количество требующих его модулей ≤floor(M/u^j). После учёта резерва и мест назначений остаётся не более 2t−1 букв на группу. Если по букве u не хватает единицы суммы ord_u, есть ещё свободное кратное u. Это обосновывает исправление за одну точку и для составной буквы. Наконец, разные буквы взаимно просты, поэтому учёт по буквам влечёт обычную делимость. Доказательство не использует ошибочного равенства ord_u(bc)=ord_u(b)+ord_u(c) для составных u.

## 5. Аудит предшествующих материалов и статус

* **Оценка через повторения.** Целиком разобрано доказательство из latest/repetition-and-stability.md архива Erdos708-Research-Dossier.zip. Два наибольших показателя для простого дают min(2,|S_{p,j}|) уже размещённых кратных на каждом уровне. При совпадении представителей в одной точке каждой паре модулей соответствует одна составная метка; метки разных рёбер взаимно просты. В дереве каждое ребро требует ещё не более одной точки: его метка делит два разных модуля и потому ≤M/2. В циклической компоненте после ориентации к циклу у каждой вершины есть исходящее ребро, а произведение входящих меток является собственным делителем модуля. Поэтому его кратное можно взять вне основной точки. Добавление r_p−2 ещё свободных кратных с наибольшими показателями исправляет все оставшиеся уровни одновременно, выбирая меньше, если свободных кратных уже недостаточно и все они взяты. Проверка довода подтверждает формулу из запроса; повторено 250 малых сравнений.

## 6. Следующий структурный вопрос

Для квадратсвободного модуля из четырёх простых есть шесть вариантов внутренней пары d. Сначала исследовать выбор этих пар. После выбора соединить типы d,e при НОД(d,e)>1. В каждой связной компоненте пробовать совместное назначение по §1. Между разными компонентами внутренние делители взаимно просты. Если в каждой компоненте назначение инъективно, то в каждой занятой точке встреченные внутренние делители попарно взаимно просты; для бонусного простого остаётся точно условие §2. Это доказанная редукция. Можно выбирать d как две средние простые каждого модуля, тогда бонус обеспечен минимальностью внешнего простого. Открытый шаг — контролировать общее условие Холла внутри больших компонент либо стоимость его нарушений. Выигрыш от возможности выбирать другие пары следует проверять вместе с возникающими циклами. Контроль одного лишь числа неразмещённых высокосоставных модулей сам по себе не даёт дешёвого исправления.

## Воспроизведение

Python 3.10+ без флага -O, внешние пакеты не нужны. Выполнить отдельно python3 check.py, python3 archive_g3.py и python3 archive_repetitions.py. Соответствующие файлы *_output.txt содержат результаты этого запуска. Новая программа проверяет реальные множества точек, их размер и делимость, начисления по антицепям, групповые и общие назначения. Численные примеры для пересекающихся d подтверждают конкретные назначения, а не величину асимптотического порога. Крупного перебора и запуска Lean не проводилось.
