# Проблема Эрдёша №708: групповой дефицит, контрпример для независимых назначений и составное исправление конфликтов

**Дата исследовательского этапа:** 25 ноября 2026 г.  
**Статус:** исследовательский отчёт с письменными аргументами. Утверждения и доказательства перенесены из предоставленного автором исследования; независимая экспертная рецензия, формальная Lean-верификация и проверка литературного приоритета не выполнены.  
**Главная цель проекта:** универсальная асимптотическая оценка \(g(n)\le(2+o(1))n\), **не доказанная** в этом отчёте.  
**Контекст:** [главный отчёт](REPORT.md), [жадные разбиения для фиксированного ранга](bounded-prime-factors.md), [растущее число простых множителей](growing-prime-factors.md).

## 1. Постановка задачи и подготовительные свойства

Пусть \(A\subseteq\{2,\dots,M\}\) — множество \(n\ge1\) **различных** целых чисел, причём \(M=\max A\). Пусть \(I\) — интервал из \(M\) последовательных целых чисел. Через \(\tau(A,I)\) обозначим минимальное число **различных** точек интервала, произведение которых делится на \(\prod_{a\in A}a\). Через \(\Omega(m)\) обозначим число простых множителей с кратностями, через \(v_p(m)\) — показатель простого \(p\).

Если \(0\in I\), достаточно одной точки. Если интервал полностью отрицателен, можно отразить его. Далее рассматривается положительный интервал. Всегда имеется делимость

\[
\prod_{a\in A}a\mid M!\mid\prod_{b\in I}b.
\tag{1.1}
\]

Первая следует из различности членов \(A\), вторая — из целочисленности биномиального коэффициента для любого положительного интервала длины \(M\).

### Лемма 1.1 (жадное двухблочное разбиение)

Каждое \(a\ge2\) допускает разбиение \(a=uv\), при котором для каждого блока \(h\in\{u,v\}\) с \(h>1\) и каждого простого \(p\mid h\) выполнено

\[
 h^2\le ap.
\tag{1.2}
\]

**Доказательство.** Выпишем простые множители \(a\) с кратностями в невозрастающем порядке. Начнём с двух единиц и каждый очередной простой множитель умножаем на меньший из текущих блоков. Если \(q\) — последний простой, добавленный к окончательному блоку \(h\), то перед этим добавлением другая сторона была не меньше \(h/q\) и затем лишь увеличивалась. В конце она равна \(a/h\), поэтому \(h/q\le a/h\), то есть \(h^2\le aq\). Поскольку \(q\) — наименьший простой делитель \(h\), получаем (1.2) для любого \(p\mid h\). \(\square\)

Два следствия используются далее:

1. Если составной блок \(h\) происходит из \(a\le M\), то \(h\le M^{2/3}\). В самом деле, наименьший простой \(q\mid h\) не больше \(\sqrt h\), и \(h^2\le Mq\le M\sqrt h\).
2. Если блоки \(h,h'\) имеют общий простой делитель \(p\), то \(h^2,(h')^2\le Mp\) и
   \[
   \operatorname{lcm}(h,h')\le\frac{hh'}p\le M.
   \tag{1.3}
   \]

Выделим произвольный полный модуль \(a_0\in A\) и кратную ему точку \(b_0\in I\), которая будет резервом. Все остальные модули разбиваем на два блока согласно лемме. Единичные блоки не требуют покрытия, простые блоки временно откладываем, а для каждого **вхождения составного блока** \(h_i\) создаём отдельную задачу с множеством представителей

\[
 V_i=\{b\in I:h_i\mid b,\ b\ne b_0\}.
\tag{1.4}
\]

При достаточно большом \(M\) по \(h_i\le M^{2/3}\) имеем \(|V_i|\ge M/(2h_i)\). Даже если блоки численно совпадают, их вхождения являются разными задачами. Для двух задач с \(\gcd(h_i,h_j)>1\) при независимом равномерном выборе \(B_i\in V_i\) вероятность совпадения оценивается как

\[
 P_{ij}:=\Pr(B_i=B_j)=\frac{|V_i\cap V_j|}{|V_i|\,|V_j|}
 \le\frac{8\gcd(h_i,h_j)}M.
\tag{1.5}
\]

Здесь используется (1.3) и \(|V_i\cap V_j|\le\lceil M/\operatorname{lcm}(h_i,h_j)\rceil\le2M/\operatorname{lcm}(h_i,h_j)\).

## 2. Точная потеря при объединении группы назначений

Пусть несколько составных меток одновременно назначены одной точке \(b\), и их непустое множество индексов равно \(S_b\). Поскольку каждая метка делит \(b\), НОК всех меток также делит \(b\). Для простого \(p\) и уровня \(j\ge1\) положим

\[
 m_b(p,j)=\#\{i\in S_b:p^j\mid h_i\}.
\]

### Лемма 2.1 (точный дефицит относительно НОК)

Число простых степенных *вхождений*, которые теряются при замене произведения группы на её НОК, равно

\[
 D_b=\sum_{p}\sum_{j\ge1}\bigl(m_b(p,j)-1\bigr)_+.
\tag{2.1}
\]

Здесь \((x)_+=\max(x,0)\). Действительно, уровень \(p^j\) появляется в произведении ровно \(m_b(p,j)\) раз, а в НОК — один раз, если присутствует. Экономия числа разных назначенных точек равна \(|S_b|-1\). Величина

\[
 R_b=D_b-(|S_b|-1)
\tag{2.2}
\]

является **точной поправкой именно в этой схеме учёта через НОК и отдельное восстановление уровней**. Она не обязана совпадать с минимальным числом дополнительных точек: само \(b\) может иметь дополнительные простые степени, а другие уже выбранные точки тоже могут помогать.

### Графовая интерпретация

Построим двудольный граф: левая доля — индексы меток из \(S_b\), правая — все присутствующие уровни \(p^j\); ребро \(i\sim(p,j)\) означает \(p^j\mid h_i\). Обозначим числа рёбер, вершин и компонент графа через \(e,v,c\), а цикломатическое число через \(\beta=e-v+c\). Тогда

\[
 D_b=e-|V_{\rm right}|,
 \qquad R_b=e-v+1=\boxed{\beta-c+1}.
\tag{2.3}
\]

Особенно важно различать два случая. Если \(s\) меток имеют **ровно один общий уровень** и в остальном не пересекаются, то \(D_b=s-1\) и \(R_b=0\). Если у тех же \(s\) меток есть \(B\) общих уровней, то \(D_b\ge B(s-1)\), и при \(B\gg1\) поправка может быть большой.

## 3. Контрпример к малости ожидаемого группового дефицита

### Теорема 3.1 (препятствие для независимого выбора)

Существуют сколь угодно большие допустимые семейства \(A\) с \(n=|A|=o(M)\), для которых жадное разбиение и **независимый равномерный выбор из полных списков** составных меток дают

\[
 \boxed{\mathbb E\sum_{b\in I}R_b\gg n\log M}.
\tag{3.1}
\]

Можно взять \(I=[1,M]\). Следовательно, утверждение \(\mathbb E\sum_bR_b=o(n)\) **неверно** для этого способа случайного назначения без дополнительных условий.

### Конструкция и подсчёт

Пусть \(T\to\infty\),

\[
 B=\left\lfloor\frac{\log_2T}{10}\right\rfloor,
 \qquad d=2^B\asymp T^{1/10}.
\]

Берём все числа

\[
 a=Pdu,
 \quad T^{0.65}<P\le T^{0.75},\quad P\text{ простое},
 \quad\frac{T}{2Pd}<u\le\frac{T}{Pd},\quad u\in\mathbb N.
\tag{3.2}
\]

Добавляем модуль \(3\), чьё кратное \(b_0=3\) резервируем. Все большие модули принадлежат \((T/2,T]\), так что \(M=\max A\asymp T\). Числа (3.2) попарно различны: \(P>\sqrt T\), тогда как \(du<T/P<\sqrt T\); поэтому большой простой множитель \(P\) однозначно распознаётся в \(a\).

Число больших модулей \(N=n-1\) равно

\[
 N=\frac{T}{2d}\sum_{T^{0.65}<P\le T^{0.75}}\frac1P
   +O(T^{0.75})\asymp\frac Td.
\tag{3.3}
\]

Здесь применена классическая оценка суммы обратных простых на степенном интервале: она стремится к \(\log(0.75/0.65)>0\); ошибка меньше главного члена. Отсюда \(n=o(M)\).

При жадном разбиении каждого \(Pdu\) первая метка равна \(P\), а вторая — \(h=du\): \(P\) идёт первым, а произведение всех оставшихся множителей \(du<P\), так что до конца остаётся на другой стороне. Первая метка проста и откладывается. **Каждая составная метка** \(h=du\) кратна общему множителю \(d=2^B\); таких задач ровно \(N\).

Всякая назначенная им точка кратна \(d\). Пусть

\[
 H=\left\lfloor\frac Md\right\rfloor\asymp N
\]

— число доступных точек, кратных \(d\), в \([1,M]\). У каждой индивидуальной метки \(h\le T^{0.35}\), поэтому \(|V_i|\gg T^{0.65}\). Вероятность \(p_{ib}\) того, что конкретная метка \(i\) назначена конкретной точке \(b\), не превосходит \(\eta=O(T^{-0.65})=o(1)\).

Обозначим \(\lambda_b=\sum_i p_{ib}\); тогда \(\sum_b\lambda_b=N\). Из независимости и неравенства \(\log(1-x)\ge-x/(1-\eta)\) при \(0\le x\le\eta\) следует

\[
 \Pr(b\text{ не занята})=\prod_i(1-p_{ib})
 \ge\exp\!\left(-\frac{\lambda_b}{1-\eta}\right).
\]

Пусть \(Z\) — число занятых точек. По выпуклости экспоненты

\[
 \mathbb EZ\le H\left(1-\exp\left[-\frac{N}{H(1-\eta)}\right]\right).
\tag{3.4}
\]

Так как \(N/H\) ограничено сверху и отделено от нуля, а \(1-e^{-x}<x\) для всякого \(x>0\), получаем

\[
 N-\mathbb EZ\gg N.
\tag{3.5}
\]

Для любой непустой группы \(S_b\) размера \(s\) все её метки содержат уровни \(2,2^2,\dots,2^B\). Поэтому

\[
 D_b\ge B(s-1),\qquad R_b\ge(B-1)(s-1).
\]

После суммирования по всем точкам

\[
 \mathbb E\sum_bR_b\ge(B-1)(N-\mathbb EZ)
 \gg N\log T\asymp n\log M.
\]

Теорема доказана на уровне приведённого письменного аргумента. \(\square\)

**Смысл контрпримера.** Он опровергает **универсальную малость ожидаемой поправки именно для независимых списочных назначений и схемы расчёта через уровни**. Он **не опровергает** оценку \(g(n)\le(2+o(1))n\). На интервале \([1,M]\) можно просто выбрать исходные числа \(A\) как точки покрытия: расход равен \(n\). Следовательно, завышение вызвано способом назначения и последующего расчёта стоимости.

## 4. Положительная теорема произвольного ранга через кратность одинаковых меток

Для каждого **числового значения** составной метки \(h\) пусть \(\mu(h)\) обозначает число её вхождений среди разбиений после удаления зарезервированного модуля. Положим

\[
 K=\max_{\mu(h)>0}h\mu(h),\qquad
 d_0(h)=\#\{t\ge1:t\mid h\}.
\]

### Теорема 4.1 (редкая повторяемость составных меток)

При достаточно большом \(M\) для оценки

\[
 \boxed{\tau(A,I)\le2n-1}
\tag{4.1}
\]

**без ограничений на \(\Omega(a)\)** достаточно условия

\[
 \boxed{\frac{K(1+\log M)}M\,
 \max_{\mu(h)>0}d_0(h)\le\frac1{64}.}
\tag{4.2}
\]

Утверждение равномерно по сдвигу интервала \(I\). Если составных меток нет, всё покрывается резервом и шагами для простых меток.

**Доказательство.** Для фиксированного вхождения \(h_i=h\), используя (1.5), допускаем переучёт по всем общим делителям \(t>1\):

\[
\begin{aligned}
\sum_{j\ne i:\gcd(h,h_j)>1}P_{ij}
&\le\frac8M\sum_{t\mid h,\ t>1}t\sum_{t\mid h'}\mu(h')\\
&\le\frac{8K}M\sum_{t\mid h,\ t>1}
       \sum_{m\le M^{2/3}/t}\frac1m\\
&\le\frac{8K}M\,d_0(h)(1+\log M)
\le\frac18.
\end{aligned}
\tag{4.3}
\]

Здесь во второй строке положено \(h'=tm\) и использовано \(\mu(tm)\le K/(tm)\), а также \(h'\le M^{2/3}\). Плохим событием является выбор одной точки двумя метками с общим простым множителем. Для события \(E_{ij}\) полагаем \(x_{ij}=2P_{ij}\). Сумма \(x\) по соседним событиям с общим индексом не больше \(1/2\), так что

\[
 x_{ij}\prod_{E\sim E_{ij}}(1-x_E)
 \ge2P_{ij}\left(1-\sum_{E\sim E_{ij}}x_E\right)\ge P_{ij}.
\]

Асимметричная локальная лемма Ловаса даёт назначение без конфликтов. В каждой занятой точке произведение назначенных ей составных меток делит точку. Остающиеся простые метки исправляются по одной новой точке каждая: если текущего показателя простого не хватает, из (1.1) следует существование невыбранного кратного этого простого. Вместе с резервом общий расход не превосходит \(1+2(n-1)=2n-1\). \(\square\)

### Следствие 4.2 (условие с запасом по степени \(M\))

Для каждого фиксированного \(\delta>0\), при достаточно большом \(M=M(\delta)\), условие

\[
 h\mu(h)\le M^{1-\delta}
 \qquad\text{для всех составных меток }h
\tag{4.4}
\]

достаточно для (4.1). Действительно, \(K\le M^{1-\delta}\), а стандартная оценка числа делителей \(d_0(h)\ll_\epsilon h^\epsilon\) при \(h\le M^{2/3}\) и достаточно малом \(\epsilon>0\) делает левую часть (4.2) стремящейся к нулю.

**Пример — семейства разных квадратов.** При жадном разбиении \(u^2\) блоки равны \(u,u\), поэтому каждая числовая составная метка \(u\) появляется не более двух раз: \(\mu(u)\le2\). Если \(u^2\le M\), то \(K\le2\sqrt M\), что обеспечивает (4.2) при достаточно большом \(M\). Число простых множителей \(u\) здесь ничем не ограничено.

## 5. Замена поштучного восстановления степеней составными требованиями

Пусть в одной точке \(b\) назначены составные метки \(h_1,\ldots,h_s\) в некотором порядке. Определим

\[
 L_j=\operatorname{lcm}(h_1,\ldots,h_j),\qquad
 c_j=\gcd(h_j,L_{j-1})\quad (2\le j\le s).
\]

### Лемма 5.1 (точное тождество составной компенсации)

\[
 \boxed{\prod_{j=1}^{s}h_j
    =L_s\prod_{j=2}^{s}c_j.}
\tag{5.1}
\]

**Доказательство.** Для каждого \(j\ge2\) имеем \(h_jL_{j-1}=L_j\gcd(h_j,L_{j-1})=L_jc_j\). Перемножая последовательные равенства, получаем (5.1). \(\square\)

Поскольку \(L_s\mid b\), после выбора одной точки \(b\) остаётся не более \(s-1\) **составных требований** \(c_2,\dots,c_s\) (единицы можно пропустить). Это ровно столько, сколько точек сэкономлено при совпадении \(s\) назначений. Важно, что один \(c_j\) может заключать множество простых степеней.

### Предложение 5.2 (достаточное условие покрытия составных требований)

Рассмотрим любое назначение всех составных меток точкам из списков (1.4), с произвольными совпадениями. Если в каждой занятой точке метки можно упорядочить так, чтобы каждый возникающий \(c_j\) был одним из следующих видов:

- \(c_j=1\);
- \(c_j\) — простое число;
- \(c_j>1\) — составное число с \((2n-1)c_j\le M\),

то

\[
 \boxed{\tau(A,I)\le2n-1.}
\tag{5.2}
\]

**Доказательство.** Сначала выбираем резерв \(b_0\) и все различные точки, на которые назначены составные метки. В группе размера \(s\) расходуется одна точка вместо \(s\), поэтому остаётся бюджет не менее \(s-1\) для требований \(c_2,\ldots,c_s\). Отложенные простые метки требуют ещё не более одной точки каждая.

Если текущий \(c_j\le M/(2n-1)\), то в любом интервале длины \(M\) имеется не менее \(2n-1\) кратных \(c_j\). Перед соответствующим добавлением по общему заранее посчитанному бюджету занято не более \(2n-2\) точек. Следовательно, свободное кратное имеется. Если \(c_j\) просто, то при недостатке его показателя существует невыбранное кратное благодаря (1.1). Если \(c_j=1\), ничего делать не требуется. По (5.1), после этих исправлений и обработки простых меток произведение выбранных точек делится на \(\prod A\), а их число не превосходит \(2n-1\). \(\square\)

**Суть нового подхода.** Избегать всех конфликтов необязательно. Поштучный учёт уровней \(p^j\) способен оценить один повторённый делитель \(2^B\) как \(B\) потерь, тогда как (5.1) позволяет восстановить его **одной** дополнительной точкой — при условии, что такую свободную точку можно найти.

## 6. Где теперь проходит граница метода

Основная нерешённая задача для этого подхода — произвольные **большие составные требования**

\[
 c_j>\frac M{2n-1}.
\tag{6.1}
\]

У таких \(c_j\) может быть слишком мало кратных в интервале, чтобы гарантировать свободное кратное простым подсчётом. Возможно, нужны более гибкие распределения представителей, другой порядок меток в группах, совместное размещение нескольких \(c_j\), дополнительные арифметические свойства исходных модулей либо качественно новый метод.

Следующая конкретная цель: получить равномерный по \(A\) и \(I\) контроль дополнительного расхода на такие **крупные составные требования** порядка \(o(n)\). Но даже эта формулировка является **направлением исследования**, не установленной леммой: может оказаться, что сама модель назначения и исправления требует дальнейшего изменения.

| Оценка \(2n-1\) для меток с редкими повторениями без ограничения на \(\Omega(a)\) | Письменное доказательство в §4; без Lean |
| Следствие для произвольных семейств различных квадратов | Следствие §4 при достаточно большом \(M\) |
| Тождество \(\prod h_j=L_s\prod c_j\) | Элементарное доказательство в §5 |
| Достаточный критерий малых составных исправлений | Письменное доказательство в §5 |
| Устранение больших составных требований для произвольных семейств | Не доказано |
| Универсальная оценка \(g(n)\le(2+o(1))n\) | **Не доказана** |
| Независимая научная экспертиза, Lean, литературный приоритет | Не выполнены / не установлены |

## 8. План следующего этапа

1. Независимо проверить контрпример §3 и оценку кратности меток §4; проверить точные условия критерия §5 и наличие крайних случаев, особенно для малых \(n\) и коротких списков.
2. Изучить возможность выбора **неравномерных или зависимых** представителей, минимизирующих число больших составных требований, а не число отдельных конфликтов.
3. Исследовать совместное назначение и покрытие требований \(c_j>M/(2n-1)\), в том числе по графам/гиперграфам делимости.
4. Если схему из §5 нельзя распространить на все семейства, построить явные препятствия **именно к способу исправления**, не смешивая их с контрпримерами к исходной гипотезе.
5. Лишь после строгой проверки пытаться перейти к универсальной оценке \(g(n)\le(2+o(1))n\).
