# Эрдёш–Сураньи №708. Арифметические сертификаты сдвига и устойчивость взвешенного оптимума

25 ноября 2026 г. Письменные доказательства, без Lean и без утверждения о литературном приоритете. Универсальный коэффициент 2 остаётся недоказанным.

Пусть A⊆[2,M] состоит из n различных чисел, I=(x,x+M] при целом x≥0. При сравнении семейств длина M остаётся фиксированной. H — минимальное число различных точек, доминирующих A по количеству кратных каждой простой степени q≤M. Тогда τ≤H: суммируем уровни по каждому простому. Во всём I кратных q не меньше ⌊M/q⌋. Если для уже выбранных точек F максимальный дефицит по уровням p равен k_p, то добавление k_p точек с наибольшими оставшимися показателями p (или всего остатка) закрывает все эти уровни. Выборы по разным p можно объединять.

## 1. Сверхлинейный диапазон: перенос ограничения с величины точки на остатки сдвига

**Теорема.** Для фиксированных ε>0, D и K пусть M≥n^{1+ε}. Положим L₀=НОК(1,…,M). Предположим, что для сдвига существует ненулевой F∈ℤ[X] степени ≤D с коэффициентами по модулю ≤M^K и F(x)≡0 mod L₀. Тогда H≤2n+O_{ε,D,K}(n^{1−η}) для некоторого η>0, единообразно по A, x и полиному. На x нет верхней границы. Достаточно даже делимости F(x) на НОК дополнительных смешанных меток, определённых ниже. Полином может зависеть от семейства и сдвига.

**Доказательство.** Атом числа — полная степень одного его простого. Разбиваем a на две взаимно простые метки, добавляя атомы по убыванию к меньшей стороне. Для последнего атома q метки h другая сторона до добавления ≥h/q. Значит h²≤Mq для каждого её атома. Смешанные метки (два и более атома) ≤M^{2/3}. При M≥(2n)^3 у каждой смешанной метки ≥2n кратных, поэтому можно разместить их инъективно и доплатить по точке за каждый отложенный атом согласно вводному правилу. Далее M≤8n³.

Составим множество всех нетривиальных унитарных делителей смешанных жадных меток; «унитарный» означает взаимную простоту делителя и частного. Положим W=M^{1−δ}, δ=min(ε,1)/20. Пока возможно, берём наименьший из этих делителей d, для которого в оставшемся семействе d r(d)≥W, где r считает унитарные вхождения. Удаляем все такие строки, назначая каждой основную метку d и дополнительную m=a/d. Для оставшихся строк сохраняем первоначальные метки. Везде откладываем одиночные атомы и пропускаем единицы. По непересечению удалённых групп Σ1/d≤n/W. Внутри одной группы m различны. Отсюда все смешанные метки ≤L=max(M^{2/3},Mn/W), а кратность дополнительных меток удовлетворяет
$$ m\mu(m)\le M\sum_d1/d\le Mn/W. $$
Действительно, вхождение m возможно лишь в группе d≤M/m, по одному разу. При наших параметрах M/L растёт не медленнее фиксированной положительной степени n: M/L=min(M^{1/3},W/n), W/n≥n^{ε−4δ} при больших n.

Из I **до назначения** выбрасываем точки x+i, где F(−i)=0 как целое число. Их ≤D. Для метки h берём список остальных кратных h, у которых частное взаимно просто с h. По включению–исключению его размер равен (M/h)∏_{p|h}(1−1/p)+O(2^{ω(h)}+D), равномерно ≥(M/h)M^{-o(1)}. Число задач данного значения не превосходит числа точных кратных в [1,M], поскольку h унитарен в своей строке и встречается в ней не более одного раза. Разность количеств точных кратных на двух интервалах длины M не превосходит 2^{ω(h)}: в каждом слагаемом разность обычных количеств кратных ≤1. Поэтому суммарное переполнение после исключения корней ≤n(L/M)M^{o(1)}: переполненных типов ≤2n/min|V_h|, каждый теряет ≤2^{ω(h)}+D. Здесь используем обычную равномерную оценку числа делителей z^{o(1)} (из e+1≤p^{ue} для больших p при любом u>0 и постоянного множителя для каждого малого p).

Остаток каждого типа назначаем равномерной инъекцией, независимо между типами. Разрешаем совместное использование точки взаимно простыми метками. Для пар без дополнительных меток ненулевое пересечение требует одинаковых показателей на всех общих простых. При общем атоме q обе метки удовлетворяют h²,k²≤Mq (свойство наследуется унитарными делителями), поэтому НОК≤M. Вероятность совпадения ≤M^{o(1)}НОД(h,k)/M. Сумма НОД по совместимым парам различных типов с общим простым ≤nW M^{o(1)}. В самом деле, для основной метки d и более поздней k их НОД t унитарен в обеих и меньше d: иначе строка k выбыла бы раньше. При извлечении d было t r(t)<W по минимальности d. Вклад поздних вхождений с данным t не выше 2W. Для пары окончательных меток применяем условие остановки. Суммирование по делителям первой метки и ≤2n вхождениям доказывает утверждение. Равные типы внутри инъекции не конфликтуют.

**Новый шаг.** Если дополнительная m назначена в b=x+i, то m делит F(x) и x+i, откуда m|F(−i). Последнее число ненулевое и по модулю ≤(D+1)M^{D+K}. Поэтому число возможных дополнительных типов в этой точке ≤M^{o_{D,K}(1)} независимо от числа делителей самого b. Суммарная ожидаемая нагрузка этих типов ≤M^{o(1)}n/W по оценкам μ(m) и |V_m|. После фиксации представителя любой одной задачи та же оценка верна для остальных типов по независимости. Итак, среднее число конфликтующих пар ≤nM^{o(1)}(W/M+n/W). Выбираем исход не хуже среднего и опускаем концы конфликтов. Для каждого p на каждом уровне недостаёт не более числа опущенных или отложенных меток с основанием p в носителе: каждая строка сохраняла всю степень p в одной метке, а две оставшиеся метки с общим p размещены в разных точках. Одна опущенная метка стоит ≤log₂ M исправлений, одноатомная — одно. Начальных мест было ≤2n. Добавка с учётом переполнений ≤n M^{o(1)}(W/M+n/W+L/M) log₂M, что даёт заявленный степенной запас. □

**Размер нового класса.** У F(X)=X(X−1) ровно 2^{π(M)} классов корней по модулю L₀: по каждой максимальной простой степени независимо выбираются 0 или 1. На позиции i все допустимые типы делят i(i+1). Для любого фиксированного B лишь O(M^B) из этих классов имеют представителя по модулю ≤M^B по абсолютной величине. Таким образом теорема охватывает сдвиги, для которых прежний перенос к малому представителю невозможен. Доля самих этих классов среди всех классов всё же стремится к нулю. Точнее, для любого фиксированного D,K число сертифицируемых классов есть o(L₀). Действительно, полиномов O(M^{K(D+1)}+1); каждый ненулевой полином имеет ≤D корней по модулю каждого простого p∈(M/2,M], кроме простых, делящих все коэффициенты. Последних O_K(1) по размеру одного ненулевого коэффициента. По КТО доля корней ≤(2 max(D,1)/M)^{π(M)−π(M/2)−O_K(1)}. Умножение на полиномиальное число полиномов сохраняет o(1). Этот аргумент относится к сертификату по полному L₀, а не к ослаблению по фактическим меткам.

## 2. Устойчивость плотной задачи к произвольным исключениям

Для весов 0≤w_p≤1, p≤M, пишем X(a)=Σ w_p v_p(a) и Q(A)=max_w[Σ_A X−Σ_I(X−1)_+]. Из LP следует Q≤τ≤Q+s, s — число простых в A: прямая задача минимизирует Σy_b+Σz_p при 0≤y_b≤1, z_p≥0, Σv_p(b)y_b+z_p≥Σ_A v_p. Исключение множителей верхних границ даёт указанную двойственную задачу. Оптимальная вершина имеет ≤s дробных y (иначе линейная зависимость соответствующих столбцов позволяет двустороннее возмущение). Округляем вверх и исправляем остаточные целые дефициты за ≤Σz_p точек, поскольку полное произведение I достаточно. Сравнивать Q разных семейств можно на общей совокупности p≤M: нулевой спрос не даёт выгоды от повышения веса.

**Теорема.** Если |A|≤M/2 и m=|A без B|≥1, то для любого B⊆[1,M] и любого положительного I
$$Q(A)\le Q(B)+C m\log(eM/m)$$
с абсолютным C. В частности при M=Θ(n) произвольные o(n) исключений в исходном семействе стоят o(n) в асимптотической задаче, если известна верхняя оценка для надсемейства остальных строк при той же длине M.

**Доказательство.** Выберем оптимальные веса A и положим μ=Σ_{p≤M}w_p/(p−1). Для равномерного U∈[1,M] имеем E X=μ−o(1) равномерно: ошибки округления для p^j≤M суммарно ≤(π(M)+√M log₂M)/M; хвосты выше M для p≤√M вносят O(√M/M), поскольку геометрический хвост каждого ≤2/M, а для больших p суммы степеней j≥2 дают O(M^{-1/2}). Для разных простых E[v_p v_r]≤1/((p−1)(r−1)) по подсчёту кратных. Имеем E v_p²≤Σ_{j≥1}(2j−1)p^{-j}=(p+1)/(p−1)^2≤3/(p−1). Поэтому E X²≤μ²+3μ. С другой стороны Σ_I X≥Σ_{[1,M]}X по уровням. Значение двойственной цели неотрицательно (допустимы нулевые веса), поэтому
$$ \mu-1-o(1)\le M^{-1}\sum_A X\le \sqrt{(\mu^2+3\mu)/2}. $$
Отсюда μ ограничено абсолютной константой.

При фиксированном 0<λ<log 2 имеем E exp(λX)≤exp(C_λ μ). Действительно, раскрываем произведение exp(λw_p v_p) по делителям с неотрицательными локальными коэффициентами exp(λw_p j)−exp(λw_p(j−1)). Частота кратных ≤обратного модуля. Получаем произведение локальных верхних оценок 1+(exp(λw_p)−1)/(p−exp(λw_p)), логарифм которого ≤C_λΣw_p/(p−1). По Йенсену среднее X на m исключениях ≤λ^{-1} log(C'M/m). Оцениваем цель A на оптимальных весах сравнением с целью B на тех же весах: банк I одинаков, а удаление B без A не увеличивает положительную добавку. Получаем теорему. □

**Следствие с перекрытиями.** Пусть M=Θ(n), n≤M/2. Допустим, все строки A кроме o(n) лежат в B, заданном произвольной булевой формулой от k условий d_i|a на [1,M], причём |B|≤2n+o(n) и 3^k=o(log M). Тогда τ(A,I)≤2n+o(n) при всех сдвигах, без ограничений на d_i и их взаимные НОД. Доказательство: индикатор формулы на {0,1}^k имеет мультилинейное разложение, коэффициент при T по обращению Мёбиуса по модулю ≤2^{|T|}; сумма модулей ≤3^k. Каждое произведение индикаторов есть кратность НОК. Поэтому для F — истинных точек формулы в I — имеем ||F|−|B||≤3^k, а для любого q также |C_F(q)−C_B(q)|≤3^k, присоединив q к НОК. Правило ремонта уровней даёт H(B,I)≤|B|+3^k(1+π(M)). Это |B|+o(n). Теперь применяем теорему устойчивости, Q(B)≤H(B,I) и τ(A,I)≤Q(A)+π(M). В доказательстве нигде не складываются независимо бюджеты перекрывающихся банков.

## 3. Проверка прежней плотной леммы и контрпример к универсальности её конструкции

Пусть P — не более одной степени каждого простого, C_A(q)>t⌊M/q⌋, |A|≤M/2. Проверим существование t<1, ρ>0 с Σ1/q≤1−ρ. При отрицании можно выбрать t→1, M→∞ и S=Σ1/q≥1−o(1). Для U равномерного на [1,M] введём Y=1_A(U), Z=Σ1_{q|U}. Имеем E YZ≥t(S−π(M)/M), E Z²≤S+S²−Σ q^{-2}. Коши и EY≤1/2 дают сначала S=O(1), затем S→1, EYZ→1, EZ²→2, EY→1/2, Σ q^{-2}→0 и E(Z−2Y)²→0. Упорядоченные пары разных q,r>√M в действительном втором моменте вообще не встречаются, поэтому их суммарный вес 1/(qr) стремится к нулю по достижению верхней грани; с диагоналями это даёт Σ_{q>√M}1/q→0. Четвёртый момент Z ограничен, поскольку k-й факториальный момент ≤S^k при k≤4. Вероятность Z≥3 стремится к нулю; по Гёльдеру третий факториальный момент тоже стремится к нулю. Для q≤M^{1/5} подсчёт различных троек снизу даёт (Σ1/q)^3−o(1): ошибка диагоналей ≤3SΣq^{-2}, ошибка округлений ≤M^{-2/5}. Значит и эта часть массы исчезает. Средняя полоса по Мертенсу вносит ≤log(5/2)+o(1)<1 (хвост суммы степеней показателя ≥2 сходится). Противоречие. Это проверяет строгость леммы именно на исходном интервале.

В I выбираем вес 1 на объединении кратных наименьшей насыщенной степени каждого p, вес t вне него. Для ненасыщенной степени вес t достаточен по определению, для насыщенной хватает всех кратных. Стоимость ≤[1−(1−t)ρ]M+o(M). Округление вершины LP по уровням добавляет ≤π(M)+√M log₂M=o(M). Получаем прежнюю полосу M≤(2+c)n при некотором c>0 (при M≤2n берём весь I).

**Барьер именно этого двухуровневого правила.** Пусть M=6n, A={6,12,…,6n}. Уже на I=[1,M] для любого 0≤t≤1 правило стоит ≥M/2−O(1), тогда как 2n=M/3. Действительно, уровень 2 имеет долю 1/3, уровень 3 — 1/2. При t<1/3 насыщен уровень 2, значит все чётные получают 1. При 1/3≤t<1/2 насыщен уровень 3, значит стоимость ≥M(t+(1−t)/3)≥5M/9. При t≥1/2 хватает одной нижней границы tM. При этом на любом сдвиге все n кратных 6 покрывают все уровни A: после деления на 6 получаем n последовательных частных, на каждом уровне их кратных ≥соответствующего количества в [1,n]. Это показывает пользу совместных составных условий и предел оптимизации одного скалярного t.

## 4. Вычислительная проверка и открытый вопрос

Самодостаточный Python 3. Проверяются остаточные сертификаты и ненулевые значения, используемые для подсчёта типов; это не перебор всех возможных сдвигов для общей гипотезы.

```python
import math,itertools
for M in [8,12,20]:
    L=math.lcm(*range(1,M+1))
    mods=[max(p**k for k in range(1,10) if p**k<=M)
          for p in range(2,M+1)
          if all(p%j for j in range(2,math.isqrt(p)+1))]
    count=0
    for choices in itertools.product(range(2),repeat=len(mods)):
        x=sum(a*(L//q)*pow(L//q,-1,q) for a,q in zip(choices,mods))%L
        for i in range(1,M+1):
            assert i*(i+1)%math.gcd(L,x+i)==0
        count+=1
    print(M,count)
# 8 16
# 12 32
# 20 256
```

Главный пробел: у произвольного сдвига может отсутствовать короткий полиномиальный сертификат, а произвольное плотное семейство может не иметь известного булева надсемейства нужного размера и сложности. Равномерной оценки потерь после исключения множества произвольных перегруженных точек не получено. Устойчивость даёт конкретную допустимую цену исключений в пространстве исходных строк и не переносится автоматически на удаление точек из целевого интервала.
