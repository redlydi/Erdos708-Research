# Эрдёш–Сураньи №708: строгий запас при плотности 1/2 и контроль фактической нагрузки

25 ноября 2026. Письменные доказательства. Общая гипотеза остаётся открытой; литературный приоритет результатов не проверен.

Пусть A — n различных чисел в [2,M], M=max A, I=[x+1,x+M] при целом x≥0. H — минимум числа точек B в I с C_B(q)≥C_A(q) для всех простых степеней q, где C считает кратные. Тогда τ≤H по суммированию показателей. Везде o(1) относится к растущему M или n. Доказаны два результата:

1. Существует абсолютное c>0: при M≤(2+c)n для всех сдвигов H≤2n для всех достаточно больших n.
2. Для фиксированных ε>0 и K≥1 при M≥n^{1+ε} и x+M≤M^K равномерно H≤2n+O_{ε,K}(n^{1-η}) с некоторым η>0. То же верно для сдвигов, сравнимых с такими x по модулю НОК(1,…,M), поскольку все условия на уровни периодичны. Абсолютного ограничения на величину самого сдвига в задаче нет.

## 1. Плотный диапазон. Лемма о почти насыщенных прогрессиях

Существуют константы 0<t<1 и ρ>0, такие что для достаточно большого M, каждого A⊆[1,M] размера ≤M/2 и любого набора P простых степеней q≤M с различными простыми основаниями,
$$ C_A(q)>t\lfloor M/q\rfloor\quad(q\in P)
\quad\Longrightarrow\quad S:=\sum_{q\in P}1/q\le 1-\rho. $$

Доказательство от противного. В случае отрицания выбираем M→∞, t→1, S≥1−o(1). Все ожидания в этом разделе — по равномерному целому U в [1,M]. Пусть Z=Σ_{q∈P}1_{q|U}, Y=1_{U∈A}. Число q не больше π(M)=o(M), поэтому E(YZ)≥t(S−o(1)). В силу взаимной простоты разных q
$$ E Z^2\le S+S^2-\sum_q q^{-2}. $$
Здесь используется верхняя оценка ⌊M/(qr)⌋/M≤1/(qr), справедливая именно в исходном интервале. По Коши (E YZ)^2≤(1/2)E Z². Эти неравенства сначала дают S=O(1) (коэффициент t² стремится к 1), потом limsup S≤1. Таким образом S→1, E(YZ)→1, E Z²→2, Σq^{-2}→0 и E(Z−2Y)^2→0. В частности max 1/q→0. Ещё одно необходимое условие равенства: сумма 1/(qr) по упорядоченным различным q,r>√M равна o(1), поскольку в действительном втором моменте все эти слагаемые равны нулю. Добавив диагональ, получаем Σ_{q>√M}1/q=o(1).

У Z равномерно ограничен четвёртый момент: его факториальный момент порядка k≤4 не превосходит S^k, по подсчёту кратных произведений различных q. Следовательно E[Z(Z−1)(Z−2)]→0. Подробно: вероятность Z≥3 стремится к нулю по L²-сходимости к 2Y, а E[Z³ 1_{Z≥3}]≤(EZ⁴)^{3/4}Pr(Z≥3)^{1/4}.

Положим R=Σ_{q≤M^{1/5}}1/q. Вклад упорядоченных различных троек таких q в третий факториальный момент не меньше R³−o(1): диагонали ограничены 3SΣq^{-2}, а суммарная ошибка целых частей ≤M^{3/5}/M. Поэтому R→0. Остаётся диапазон (M^{1/5},√M]. Сумма обратных чисел по степеням с показателем ≥2 и величиной >M^{1/5} есть o(1), поскольку ряд Σ_p Σ_{k≥2}p^{-k} сходится. Для простых по теореме Мертенса сумма в этом диапазоне равна log(5/2)+o(1)<1. Это противоречит S→1. Лемма доказана. Довод существования не даёт численного значения используемых констант.

## 2. Округление в плотном случае

Пусть M≥2n. Для каждого p выберем наименьшее q=p^j с C_A(q)>t⌊M/q⌋, если такое q существует. Пусть V — объединение кратных выбранных степеней в I. По лемме и оценке ошибки целых частей |V|≤(1−ρ)M+π(M). Назначим дробный вес 1 точкам V и t всем остальным. Это допустимое покрытие каждого уровня: насыщенные уровни содержатся в кратных выбранной минимальной степени, а для любого ненасыщенного уровня t C_I(q)≥C_A(q). Стоимость ≤[1−(1−t)ρ]M+o(M).

Рассмотрим LP минимума стоимости в кубе [0,1]^M со всеми этими ограничениями по уровням. В оптимальной вершине число строго дробных координат не больше числа ограничений по уровням (иначе соответствующие столбцы линейно зависимы и возможно двустороннее возмущение). Это число ≤π(M)+√M log₂M=o(M). Округление вверх сохраняет допустимость. Итак H≤(1−λ)M+o(M), λ=(1−t)ρ>0, равномерно при n≤M/2. Выбираем любое c>0 с (1−λ)(2+c)<2. Тогда при 2n≤M≤(2+c)n получаем H≤2n для больших n. При M<2n берём весь I. Это также доказывает Q≤2n в указанной полосе.

Для проверки исходной LP-редукции положим D_p=Σ_A v_p(a). Минимизируем Σ y_b+Σ z_p при 0≤y_b≤1, z_p≥0 и Σ v_p(b)y_b+z_p≥D_p. Максимум двойственной задачи после исключения множителей верхних границ равен Q=max_{0≤w≤1}[Σw_pD_p−Σ_b(Σ_p w_p v_p(b)−1)_+]. Целое покрытие допустимо, поэтому Q≤τ. В вершине ≤s дробных y (тот же аргумент по столбцам при фиксированных z), округляем их вверх. По каждому p остаётся целый дефицит ≤z_p. Пока показатель недостаточен, есть ещё не выбранное кратное p, так как C_I(q)≥C_A(q) на всех уровнях. Исправления стоят ≤Σz_p. Это даёт τ≤Q+s, но для теоремы 1 использовано более сильное округление непосредственно по уровням.

## 3. Унитарное извлечение и точечная нагрузка

Приводим доказательство используемой части предыдущей редукции. Атом a — полная степень одного простого в a. Жадно раскладываем атомы по невозрастанию по двум блокам, умножая меньшую сторону. Для блока h последний добавленный атом q удовлетворяет h/q≤a/h, откуда h²≤Mq для любого его атома. Смешанный блок (не менее двух атомов) ≤M^{2/3}. Если M≥(2n)^3, все смешанные блоки можно разместить на разных кратных жадно (каждый имеет ≥2n вариантов), одноатомные отложить. Для p дефицит на каждом уровне ≤числа отложенных p-атомов. Выбирая столько точек с наибольшими оставшимися v_p или весь остаток, покрываем сразу все уровни по p. Затраты ≤2n. Далее M≤8n³.

Пусть D — все нетривиальные унитарные делители первоначальных смешанных блоков (d унитарен, если gcd(d,a/d)=1). Выберем W=M^{1−δ}, где δ=min(ε,1)/20. Из оставшихся строк удаляем группы по наименьшему d∈D с d r(d)≥W, где r(d) считает унитарные вхождения d в оставшихся строках. Каждой строке группы даём метки d и m=a/d. После остановки сохраняем исходные блоки у оставшихся строк. Все пары унитарны. Основные метки d удовлетворяют Σ1/d≤n/W по непересечению удалённых групп. Дополнительные m в группе различны и ≤M/d≤Mn/W. Все смешанные метки ограничены L=max(M^{2/3},Mn/W), где M/L≥n^κ для некоторого κ(ε)>0.

Для h используем V_h={b∈I:h унитарно делит b}. Включение–исключение даёт |V_h|=(M/h)∏_{p|h}(1−1/p)+O(2^{ω(h)})≥(M/h)M^{-o(1)}. Здесь число делителей τ₀(h)=M^{o(1)} равномерно для h≤M: для любого u>0 при больших p выполняется e+1≤p^{ue}, для конечного числа малых p достаточно постоянных множителей. Кратность метки не выше числа её точных представителей в [1,M] по различности строк. Два интервала равной длины отличаются по количеству кратных любого модуля не более чем на один. Отсюда переполнение списка ≤2^{ω(h)} по включению–исключению. Число переполненных типов ≤2n/min|V_h|, поэтому потеря ≤n(L/M)M^{o(1)}. Для оставшихся задач одного значения берём равномерную случайную инъекцию в список, для разных значений независимо; одноатомные задачи отложены.

Рассмотрим пары без дополнительных меток. Несовместимые показатели общего простого исключают совпадение. Для совместимых меток с общим атомом q имеем h²,k²≤Mq (это наследуют унитарные делители жадного блока), поэтому НОК≤M. Вероятность совпадения ≤M^{o(1)}gcd(h,k)/M. Сумма НОД по разным таким значениям с общим простым, с учётом вхождений, ≤nW M^{o(1)}. В самом деле, для ранней основной метки d и поздней k величина t=gcd(d,k)>1 унитарна в обеих. Она строго меньше d, иначе поздняя строка была бы удалена. До удаления d по минимальности t r(t)<W. Значит для фиксированного d вклад поздних вхождений на данный делитель t не больше 2W. Для двух конечных меток действует то же по остановке. Суммируем по ≤τ₀(h) делителям и ≤2n первым вхождениям. Равные значения разнесены инъекцией. Таким образом среднее число этих конфликтов ≤nM^{o(1)}W/M.

**Дополнительные метки на одной точке.** Кратность μ_доп(m) не выше числа извлечённых групп d с d≤M/m. Следовательно
$$m\mu_{доп}(m)\le M\sum_d1/d\le Mn/W.$$
В любой точке b ожидаемое число дополнительных смешанных назначений не больше
$$\sum_{m|b}\mu_{доп}(m)/|V_m|\le \tau_0(b) M^{o(1)} n/W.$$
Сумма берётся только по используемым m, в точной версии можно оставить лишь унитарные m. При b≤M^K это ≤M^{o_K(1)}n/W. Для фиксированного вхождения другого значения условимся на месте его назначения. Выборы дополнительных задач отличных значений остаются независимыми от этого условия; тот же верхний предел действует для их суммарной нагрузки. Равные значения никогда не сталкиваются. Суммируя по ≤2n первым вхождениям, получаем ≤2n M^{o_K(1)}n/W ожидаемых пар с дополнительной меткой. Это доказательство не усредняет сдвиг и учитывает все встречи в точке одновременно.

Удаляем концы конфликтующих пар, включая только встречи с общим простым для основных и конечных. Есть назначение с числом удалений и переполнений
$$\ll n M^{o_K(1)}(W/M+n/W+L/M).$$
Каждое слагаемое в скобках убывает как фиксированная степень n. Оставшиеся метки в точке взаимно просты. Каждый пропущенный смешанный блок стоит ≤ω(h)≤log₂M по правилу одновременного исправления уровней из начала раздела. Начальный бюджет двух меток на строку даёт теорему 2. Перенос по периоду в формулировке касается H и проверяется непосредственно для q≤M.

## 4. Перепроверка утверждения о почти всех сдвигах и граница нового результата

Для произвольных сдвигов вклад дополнительных меток в сумму НОД для фиксированного z не выше Σ_d τ₀(z)M/d: в каждой группе все m различны и ≤M/d, а Σ_{m≤M/d} gcd(m,z)≤Σ_{t|z}t⌊M/(dt)⌋. Значит полный вклад НОД для совместимых пар ≤nM^{o(1)}(W+Mn/W). Вероятность конфликта двух значений ограничена количеством кратных их НОК в I, умноженным на M^{o(1)}hk/M². Для T последовательных сдвигов среднее количество кратных ℓ≤любого размера ограничено M/ℓ+M/T: суммируем по каждой из M позиций. Получаем среднее число конфликтов ≤nM^{o(1)}(W/M+n/W+nL²/(MT)). При T≥M² последнее слагаемое ≤n/M. Неравенство Маркова и тот же ремонт дают ранее заявленную оценку вне доли O(n^{-η}) сдвигов для некоторого η>0. Для каждого отдельного сдвига вместо M/T стоит 1; нормированная погрешность nL²/M² мала при M≥n^{3/2+ε} с выбранным δ. Это независимо восстанавливает оба использованных пороговых аргумента.

Контрпример к попытке оценить число делителей точки независимо от сдвига: в интервал вокруг кратного НОК(1,…,M) попадает точка, кратная всем m≤M. Для унитарного аналога берём произведение всех простых ≤M: каждый квадратсвободный m≤M является его унитарным делителем. Следовательно, нельзя перенести использованное ограничение на число типов в одной точке на произвольный сдвиг. Это не контрпример к общей гипотезе. Аналогично во втором моменте плотной леммы неравенство C(qr)≤M/(qr) существенно относится к [1,M]; в сдвинутом интервале оно может быть неверно уже при qr>M и общей кратной точке.

Открыты, в частности, все константы отношения M/n далеко за доказанным соседством 2 и исключительные неполиномиальные сдвиги промежуточного диапазона. Перспективно исключать немного точек с аномальной нагрузкой до выбора инъекций, оценивая возникшее переполнение по типам; одного примера большой нагрузки недостаточно для оценки стоимости их удаления.

## 5. Проверка реализации плотного сертификата

Самодостаточный Python 3. Проверяются все уровни при нескольких сдвигах, включая 209, и всех семействах половинной плотности для малых M. Порог 0.9 выбран лишь для проверки построения дробного покрытия; тест не утверждает, что он даёт теоретический запас ρ.

```python
from itertools import combinations
checks = 0
for M in range(3,13):
    for A in combinations(range(1,M+1),M//2):
        P = []
        for p in (2,3,5,7,11):
            q = p
            while q <= M:
                if 10*sum(a%q==0 for a in A)>9*(M//q):
                    P.append(q)
                    break
                q *= p
        for x in (0,17,209):
            for p in (2,3,5,7,11):
                q = p
                while q <= M:
                    mass = sum(10 if any(b%h==0 for h in P) else 9
                               for b in range(x+1,x+M+1) if b%q==0)
                    assert mass >= 10*sum(a%q==0 for a in A)
                    q *= p
            checks += 1
print(checks)  # 5724
```
