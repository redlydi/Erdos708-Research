# Erdős–Surányi №708: оценка \(2n-1\) при ограниченном числе простых множителей

**Дата:** 25 ноября 2026 г.  
**Тип:** исследовательский математический отчёт с полным письменным доказательством.  
**Статус:** аргумент представлен и проверен на уровне основных математических переходов; независимая экспертная рецензия, Lean-верификация и проверка приоритета в литературе отсутствуют. Порог \(M_0(k)\) не вычислен.  
**Контекст:** [основной отчёт](REPORT.md), [предыдущие результаты для четырёх простых](four-prime-lll%20%281%29.md), [постановка №708](https://www.erdosproblems.com/708).

## 1. Определения и главный результат

Пусть \(A\subseteq\{2,3,\ldots,M\}\) — множество \(n\ge1\) **различных** целых чисел, причём \(M=\max A\). Пусть \(I\) — интервал из ровно \(M\) последовательных целых чисел. Через \(\tau(A,I)\) обозначим минимальное число **различных** точек \(b\in I\), произведение которых делится на
\[
Q_A=\prod_{a\in A}a.
\]

Через \(\Omega(a)\) обозначим число простых множителей \(a\) **с учётом кратности**. Например, \(\Omega(12)=3\) и \(\Omega(1)=0\).

### Теорема 1 (ограниченное число простых множителей)

Для каждого фиксированного целого \(k\ge1\) существует число \(M_0(k)\) такое, что для любого \(M\ge M_0(k)\), любого множества различных чисел \(A\subseteq\{2,\ldots,M\}\), у которого \(\Omega(a)\le k\) для всех \(a\in A\), и любого интервала \(I\) из \(M\) последовательных целых чисел выполняется
\[
\boxed{\tau(A,I)\le2n-1},\qquad n=|A|.
\]

В частности, утверждение распространяется на любые произведения **четырёх различных простых**, независимо от размеров и совпадения простых между различными модулями. Поскольку \(n\) различных чисел из \(\{2,\ldots,M\}\) требуют \(M\ge n+1\), для фиксированного \(k\) оценка действует для всех достаточно больших \(n\). Случай малых \(M<M_0(k)\) здесь не закрыт.

В этом доказательстве не используются предположения о степени графа ядер и о сравнимости простых множителей.

## 2. Лемма о жадном разбиении

### Лемма 2

Для каждого \(a\ge2\) существуют целые \(u,v\ge1\) с \(a=uv\), обладающие следующим свойством: для каждого \(h\in\{u,v\}\) с \(h>1\) и каждого простого \(p\mid h\)
\[
\boxed{h^2\le ap}.\tag{2.1}
\]

**Доказательство.** Выпишем все простые множители \(a\), считая повторы, в невозрастающем порядке. Начнём с \(u=v=1\). Очередной простой множитель умножим на меньший из текущих продуктов \(u,v\); при равенстве сторону выбираем произвольно.

Возьмём одну из получившихся сторон \(h>1\) и обозначим через \(q\) последний добавленный в неё простой. Поскольку множители перебираются по невозрастанию, \(q\) — наименьший простой делитель \(h\). Непосредственно перед добавлением \(q\) рассматриваемая сторона имела значение \(h/q\). По правилу выбора другая сторона в этот момент была не меньше \(h/q\); после этого её значение могло только увеличиваться. В конце оно равно \(a/h\). Поэтому
\[
\frac hq\le\frac ah,\qquad h^2\le aq\le ap\quad\text{для любого }p\mid h.
\]
Получено (2.1). \(\square\)

### Следствие 2.1: контроль НОК конфликтующих меток

Пусть числа \(a,a'\le M\) разбиты по лемме 2 и \(h\mid a\), \(h'\mid a'\) — две получившиеся неединичные метки. Если \(p\mid\gcd(h,h')\) — общий простой делитель, то из (2.1)
\[
h\le\sqrt{Mp},\qquad h'\le\sqrt{Mp},
\]
а значит,
\[
\operatorname{lcm}(h,h')=\frac{hh'}{\gcd(h,h')}\le\frac{hh'}p\le M.\tag{2.2}
\]

Это верно и при \(h=h'\), и для меток, принадлежащих одному исходному модулю.

### Следствие 2.2: размер составной метки

Если \(h\) составное, его наименьший простой делитель \(q\) удовлетворяет \(q\le\sqrt h\). Из (2.1) следует
\[
h^2\le Mq\le M\sqrt h,
\quad\Longrightarrow\quad
\boxed{h\le M^{2/3}}.\tag{2.3}
\]
Следовательно, \(M/h\ge M^{1/3}\): у каждой **составной** метки много кратных в интервале длины \(M\). Простые метки будут обработаны отдельно.

## 3. Разреженность чисел с малым числом простых множителей

Для целого \(j\ge0\) положим
\[
F_j(y)=\#\{m\in\mathbb N:1\le m\le y,\ \Omega(m)\le j\}.
\]

### Лемма 3

При каждом фиксированном \(j\ge0\)
\[
\boxed{F_j(y)=o(y)\qquad(y\to\infty)}.\tag{3.1}
\]

**Доказательство.** При \(j=0\) считаем только единицу, поэтому \(F_0(y)\le1=o(y)\).

Проведём индукцию по \(j\). Зафиксируем число \(z\ge2\) и положим \(W=\prod_{p\le z}p\). Среди чисел до \(y\) взаимно простых с \(W\) не больше
\[
\frac{\varphi(W)}W y+O_z(1).
\]
Каждое из остальных чисел \(m\), удовлетворяющих \(\Omega(m)\le j\), имеет некоторый простой делитель \(p\le z\), после деления на который число простых множителей становится не больше \(j-1\). Поэтому
\[
F_j(y)\le \frac{\varphi(W)}W y+O_z(1)+\sum_{p\le z}F_{j-1}(y/p).
\]
При фиксированном \(z\) последняя сумма равна \(o_z(y)\) по индукционному предположению. Делим на \(y\), берём верхний предел при \(y\to\infty\) и получаем
\[
\limsup_{y\to\infty}\frac{F_j(y)}y\le\frac{\varphi(W)}W=\prod_{p\le z}\left(1-\frac1p\right).
\]
По расходимости суммы обратных простых (или классическому произведению Эйлера) правая часть стремится к нулю при \(z\to\infty\). Лемма доказана. \(\square\)

### Лемма 4: число вхождений меток, делящихся на \(t\)

Пусть все исходные модули \(a\in A\) удовлетворяют \(\Omega(a)\le k\), и каждый разбит на две метки по лемме 2. При любом целом \(t>1\) число **вхождений** меток, кратных \(t\), не превышает
\[
\boxed{2F_{k-1}(M/t)}.\tag{3.2}
\]

**Доказательство.** Если хотя бы одна метка модуля \(a\) кратна \(t\), то \(t\mid a\). Поэтому различные такие модули \(a\) дают различные числа \(a/t\le M/t\), и
\[
\Omega(a/t)=\Omega(a)-\Omega(t)\le k-1,
\]
так как \(t>1\). Число модулей не превышает \(F_{k-1}(M/t)\). Каждый исходный модуль даёт ровно две позиции (метки), поэтому число вхождений не превосходит удвоенного числа модулей. \(\square\)

Важно: позиции учитываются **с кратностью**, даже если две метки одного модуля численно равны или имеют общий простой множитель.

## 4. Локальная лемма Ловаса: оценка конфликтов

**Подготовка.** Если \(0\in I\), выбираем ноль. Если все числа в \(I\) отрицательные, отражаем интервал. Далее \(I\) положителен.

Выберем произвольный модуль \(a_0\in A\) и одну его кратную точку \(b_0\in I\). Такая точка обязательно есть, поскольку \(a_0\le M\) и в любых \(M\) последовательных целых есть кратное любого \(a_0\le M\). Выделим эту точку в **резерв** и удалим \(a_0\) из системы назначений.

Для каждого оставшегося \(a\in A\setminus\{a_0\}\) возьмём обе метки \(u_a,v_a\) из леммы 2. Единичные метки ничего не требуют, а **простые** метки временно отложим. Для каждого *вхождения составной метки* \(h_i\) заведём собственную задачу \(i\) и список
\[
V_i=\{b\in I: h_i\mid b,\ b\ne b_0\}.
\]
Списки могут совпадать у разных задач.

Из (2.3) и числа кратных в интервале длины \(M\) при достаточно большом \(M\), одинаковом для всех меток,
\[
|V_i|\ge\left\lfloor\frac M{h_i}\right\rfloor-1
\ge\frac M{2h_i}.\tag{4.1}
\]
Для последнего неравенства достаточно \(M/h_i\ge4\); это следует из \(M/h_i\ge M^{1/3}\) при \(M\ge64\).

Независимо и равномерно выберем \(B_i\in V_i\) для каждой составной метки. Для каждой пары **различных задач** \(i\ne j\) с \(\gcd(h_i,h_j)>1\) введём плохое событие
\[
E_{ij}=\{B_i=B_j\}.
\]
Его вероятность равна
\[
P_{ij}=\frac{|V_i\cap V_j|}{|V_i|\,|V_j|}.
\]
Из (2.2) \(\operatorname{lcm}(h_i,h_j)\le M\), поэтому число общих кратных в \(I\) не больше
\[
\left\lceil\frac M{\operatorname{lcm}(h_i,h_j)}\right\rceil
\le \frac{2M}{\operatorname{lcm}(h_i,h_j)}.
\]
С учётом (4.1) получаем
\[
\boxed{P_{ij}\le\frac{8\gcd(h_i,h_j)}M}.\tag{4.2}
\]
Эта оценка покрывает и совпадающие числовые метки.

Зафиксируем задачу \(i\) с меткой \(h=h_i\). Для любой конфликтующей задачи \(j\) величина \(\gcd(h,h_j)\) является одним из делителей \(h\), больших 1. Поэтому
\[
\begin{aligned}
\sum_{\substack{j\ne i\\\gcd(h,h_j)>1}}P_{ij}
&\le\frac8M\sum_{\substack{t\mid h\\t>1}}
 t\,\#\{j:t\mid h_j\}\\
&\le16\sum_{\substack{t\mid h\\t>1}}\frac{F_{k-1}(M/t)}{M/t}.
\end{aligned}\tag{4.3}
\]
Во второй строке использована лемма 4. Можно суммировать по *всем* меткам исходного семейства, а не только составным оставшимся: это только увеличивает правую часть.

Поскольку \(h\mid a\) для некоторого \(a\) с \(\Omega(a)\le k\), число положительных делителей \(h\) не больше \(2^k\). Для каждого \(t\mid h\) верно \(t\le h\le M^{2/3}\), откуда \(M/t\ge M^{1/3}\). Следовательно, правая часть (4.3) не больше
\[
16\,2^k\sup_{y\ge M^{1/3}}\frac{F_{k-1}(y)}y
\xrightarrow[M\to\infty]{}0
\quad\text{при фиксированном }k.\tag{4.4}
\]
Выберем \(M_0(k)\) настолько большим, чтобы при \(M\ge M_0(k)\) одновременно выполнялись (4.1) и
\[
\sum_{\substack{j\ne i\\\gcd(h_i,h_j)>1}}P_{ij}\le\frac18
\qquad\text{для каждой задачи }i.\tag{4.5}
\]

**Применение асимметричной локальной леммы Ловаса.** Отбросим события с \(P_{ij}=0\), для остальных положим \(x_{ij}=2P_{ij}\). Из (4.5) следует \(0<x_{ij}\le1/4<1\). Два события независимы, если у них нет общих индексов задач. Для любого \(E_{ij}\) сумма \(x\) по событиям, разделяющим с ним хотя бы одну переменную, не превышает
\[
2\left(\frac18+\frac18\right)=\frac12.
\]
По неравенству \(\prod(1-x_E)\ge1-\sum x_E\) для \(x_E\in[0,1]\)
\[
x_{ij}\prod_{E\sim E_{ij}}(1-x_E)
\ge2P_{ij}\left(1-\sum_{E\sim E_{ij}}x_E\right)
\ge P_{ij}.
\]
Условия локальной леммы выполнены, и существует назначение представителей составных меток **без плохих событий**.

## 5. Финальная делимость и точный подсчёт точек

Пусть \(B\) — множество **различных** точек, назначенных всем составным меткам. В одной точке \(b\in B\) могут встретиться несколько задач, но их метки попарно взаимно просты: любые две с общим простым множителем образовали бы запрещённое событие. Каждая назначенная метка делит \(b\). Следовательно, произведение **всех** составных меток, назначенных в \(b\), также делит \(b\). Перемножая по различным \(b\in B\), заключаем, что
\[
\prod_{\text{вхождения составных меток }h_i}h_i
\quad\Bigm|\quad\prod_{b\in B}b.
\]
Точка \(b_0\) не входит ни в один список и покрывает весь исходный \(a_0\).

Остаются только **простые метки** из разбиений других модулей; метки, равные 1, игнорируются. На каждое простое вхождение \(p\) можно добавить не больше одной новой точки. Действительно, для положительного \(I=\{u+1,\ldots,u+M\}\) имеем
\[
\prod_{a\in A}a\ \Bigm|\ M!\ \Bigm|\ \prod_{b\in I}b,
\qquad
\prod_{b\in I}b=M!\binom{u+M}{M}.
\]
Первая делимость верна, поскольку \(A\) — множество **различных** чисел из \(\{2,\ldots,M\}\). Если в произведении уже выбранных точек не хватает показателя простого \(p\), то среди **ещё не выбранных** точек обязательно есть кратное \(p\); иначе все кратные \(p\) из \(I\) уже были бы выбраны и обеспечивали бы весь показатель \(p\), доступный в произведении полного интервала, достаточный для цели. Добавляем такую точку и повторяем, учитывая фактическое новое произведение.

У каждого \(a\in A\setminus\{a_0\}\) в разбиении ровно две позиции. Каждая позиция обходится **не более чем одной** новой точкой: составная — за счёт назначения, простая — за счёт последующего исправления, единица — бесплатно. Занятые одним и тем же числом позиции не увеличивают число **различных** точек. Вместе с резервом получаем
\[
\tau(A,I)\le1+2(n-1)=\boxed{2n-1}.
\]
Теорема 1 доказана. \(\square\)

## 6. Проверенные следствия и границы

| Утверждение | Статус |
| --- | --- |
| Лемма о жадном разбиении \(h^2\le ap\) | Письменное доказательство в §2 |
| \(\operatorname{lcm}(h,h')\le M\) при общем простом делителе | Следует из леммы о разбиении |
| Критерий малой суммы конфликтов через \(F_{k-1}\) | Письменное доказательство в §§3–4 |
| \(\tau(A,I)\le2n-1\) при \(\Omega(a)\le k\), \(k\) фиксировано и \(M\ge M_0(k)\) | Полное письменное доказательство в §§1–5; без Lean |
| Случай четырёх **различных** простых при всех достаточно больших \(n\) | Следствие при \(k=4\) и \(M\ge n+1\) |
| Случай \(k=4\) **для всех** \(M\) | Не исследован конечный диапазон \(M<M_0(4)\) |
| Общая оценка \(g(n)\le(2+o(1))n\) без ограничения на \(\Omega(a)\) | Здесь **не доказана** |
| Научный приоритет | Не установлен |
| Формальная Lean 4-верификация | Не выполнена |

Отметим, что доказательство существования \(M_0(k)\) **не даёт явного вычисленного порога**. Само по себе оно не даёт алгоритма, который эффективно находит назначение в произвольном большом экземпляре; локальная лемма используется как теорема существования.

## 7. Независимый конечный тест жадного разбиения

Для проверки реализации жадного алгоритма проведён отдельный расчёт при \(M=5000\):

- все \(4999\) числа \(a=2,\ldots,5000\) разбиты на два множителя и проверено \(h^2\le ap\) для каждого простого делителя каждой неединичной метки;
- получено \(761\) **различных** неединичных меток;
- для всех \(2315\) неупорядоченных пар **различных** меток с общим простым делителем проверено \(\operatorname{lcm}(h,h')\le5000\);
- нарушений не найдено.

Это **проверка частных конечных случаев**, не доказательство теоремы; доказательство дано выше. Пример кода воспроизведения:


a) Вычислить наименьшие простые делители всех чисел до 5000 обычным решетом.  
b) Для каждого \(a\) факторизовать его с кратностями, отсортировать простые в невозрастающем порядке и жадно распределить между двумя текущими произведениями.  
c) Проверить (2.1) для каждой метки и каждого её простого делителя.  
d) Собрать множество различных неединичных меток и проверить (2.2) для каждой пары с НОД больше 1.

## 8. Дальнейшие математические задачи

1. Получить полезную **явную** или вычислимую оценку \(M_0(k)\), особенно для \(k=4\), а затем закрыть небольшой остаток по \(M\) отдельными аргументами или сертифицированным перебором.
2. Исследовать режим \(k=k(M)\), когда число простых множителей растёт вместе с \(M\). Главный барьер — оценка (4.4), использующая \(2^k\) делителей и \(F_{k-1}(y)=o(y)\) лишь для фиксированного \(k\).
3. Вместо грубой суммы по всем делителям попробовать оценивать непосредственно
   \[
   \frac1M\sum_{\substack{j\ne i\\\gcd(h_i,h_j)>1}}\gcd(h_i,h_j),
   \]
   допуская небольшое число перегруженных меток с отдельным исправлением.
4. Независимо проверить доказательство, его формулировку относительно точного определения \(g(n)\) в №708 и литературный приоритет. **Не** считать отсутствие найденной ошибки математической сертификацией.
