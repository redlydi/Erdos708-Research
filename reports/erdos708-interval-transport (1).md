## 1. Постановка и аудит использованных результатов

A — n различных натуральных чисел ≥2, M=max A, I состоит из M последовательных целых. Минимизируется число различных точек, произведение которых кратно произведению A. Работаем с «не более» точек. Если 0∈I, одной достаточно. Отрицательный интервал отражаем.

Пусть C_X(q) — число элементов конечного набора X, кратных q (для мультимножества — с кратностью). Для каждой простой степени q имеем C_I(q)≥⌊M/q⌋≥C_A(q). Это следует из длины интервала и различности исходных чисел. В частности, произведение всего I кратно произведению A. Символ ω означает число **различных** простых делителей, ω(1)=0.

Сверены group-deficit-and-repair.md, связанные аргументы growing-prime-factors.md, bounded-prime-factors.md и общий REPORT.md в redlydi/Erdos708-Research. Использованные ниже переходы проверяются следующим образом.

* В жадном разбиении простых множителей по невозрастанию между двумя сторонами последний множитель q, добавленный на сторону h, наименьший на этой стороне. До добавления другая сторона была ≥h/q, потому h²≤aq. Для составного h отсюда h≤M^{2/3}, для меток с общим простым p имеем НОК≤hh′/p≤M.
* При замене пары на НОК и НОД два показателя каждого простого переставляются в порядке убывания. Это доказывает тождество произведений и сохранение суммы любой функции этих двух показателей. По каждому уровню p^j замена всей группы на один НОК теряет ровно (m(p,j)−1)_+ вхождений. Это потеря в назначении, а не обязательный расход точек.
* Для проверки §4 последнего отчёта: после исключения зарезервированной точки список составной метки h имеет ≥M/(2h) элементов при большом M. Пересечение конфликтующей пары имеет ≤2M/НОК элементов. При K=max hμ(h) сумма вероятностей событий с данным индексом ≤(8K/M)τ₀(h)(1+log M), где τ₀ — число делителей: для каждого t|h суммируем tμ(tm)≤K/m. При правой части ≤1/8 веса событий x=2P имеют сумму по соседям одного события ≤1/2, поскольку у него два индекса. Тогда x∏(1−x′)≥P, и асимметричная локальная лемма применима к независимым переменным выбора точек. На одной точке оставшиеся метки взаимно просты. Резерв учитывается один раз. Простые остатки лучше вносить в самом конце: имеющегося общего произведения достаточно, чтобы добавить по одной точке на единицу недостающего показателя. Аналогично в предложении 5.2 сначала размещаются все малые составные остатки на свежих точках и лишь затем простые. Это уточнение порядка исключает двойной учёт. Противоречия в этих выводах не обнаружено.
* В примере §3 большие модули различны по единственности P>√T и частного. Сумма ошибок от округления по P равна O(T^{0.75})=o(T/d). При независимых назначениях в H≈n ячеек вероятности отдельных попаданий ≤η=o(1). По неравенству для log(1−x) вероятность пустоты ячейки нагрузки λ не меньше exp(−λ/(1−η)). Выпуклость в сумме по H ячейкам и N/H, отделённое от нуля и бесконечности, дают N−E Z≫N, где Z — число занятых ячеек. Каждое совпадение сверх первого теряет B общих двоичных уровней и экономит одну точку. Поэтому вывод об ожидаемой поправке ≫n log M для прежней схемы сохраняется. ## 2. Два способа дополнить уже выбранные точки

**Лемма 1 (уровни).** Для F⊆I положим
$$k_p=\max_{j\ge1}(C_A(p^j)-C_F(p^j))_+.$$
Тогда τ≤|F|+Σ_p k_p. Для каждого p выбираем до k_p точек из I∖F с наибольшими v_p, либо весь остаток, если он меньше. На уровне j новое количество кратных не меньше min(C_I(p^j),C_F(p^j)+k_p), а это ≥C_A(p^j). Объединение сделанных отдельно по p выборов сохраняет все неравенства. Суммирование по j доказывает делимость. Эта оценка требует доминирования на каждом уровне; для делимости может хватать меньшего.

**Лемма 2 (усечённые показатели).** Пусть для каждого p задано целое k_p≥0, причём для всех целых t≥0
$$
\sum_{a\in A}\min(v_p(a),t)
\le \sum_{b\in F}\min(v_p(b),t)+k_pt .
$$
Тогда снова τ≤|F|+Σk_p.

Доказательство. Для фиксированного p пишем v_x=v_p(x). Сумма k наибольших показателей в I∖F, с дополнением нулями, равна min по целым t≥0 выражения kt+Σ_{I∖F}(v_b−t)_+. Это видно по упорядочиванию; можно выбрать t равным (k+1)-му показателю, включая дописанные нули. Прибавив Σ_F v_b, получим минимум выражения Σ_I(v_b−t)_+ + Σ_F min(v_b,t)+kt. Первое слагаемое ≥Σ_A(v_a−t)_+ по подсчёту уровней выше t. По условию весь минимум ≥Σ_A v_a. Объединяем выборы по простым. □

**Следствие 2.1 (крупные простые степени при составном исправлении).** В схеме последнего отчёта с резервом и любыми допустимыми назначениями составных меток пусть c пробегает остатки НОД при последовательном присоединении меток к НОК. Тогда
$$\tau\le 2n-1+\sum_c(\omega(c)-1)_+.$$
В частности, все остатки, являющиеся степенями простых, исправимы в пределах 2n−1, без ограничения размера, показателя или необходимости свободного кратного данной степени. В сумме можно исключить и любые остатки, которые уже удалось назначить различным дополнительным свободным точкам, кратным своим остаткам.

Доказательство. Берём резерв, по одной точке на занятую группу и точки для уже размещённых остатков. Их множество обозначим F. В качестве оставшихся требований оставляем отложенные простые и неразмещённые НОД. Для каждого p положим k_p равным числу этих требований, делящихся на p. При разбиении исходного показателя x+y на x,y сумма усечений min(·,t) может только возрасти. При операции НОК–НОД она сохраняется для каждого простого. Уже размещённые требования (резерв, НОК и дополнительные остатки) покомпонентно не превосходят показателей своих **различных** точек. Каждое свободное требование с p в носителе вносит в усечённую сумму ≤t. Выполнено условие леммы 2. Группа из s вхождений расходует одну начальную точку и оставляет s−1 мест на исправления. Один неразмещённый c стоит ≤ω(c), единица стоит ноль. Вне резерва было не больше 2(n−1) блоков, включая простые. Это даёт формулу. □

## 3. Совместное размещение составных делителей на прогрессиях

**Теорема 3.** Разобьём A на группы i размера N_i. В группе выберем записи a=d_i u_a r_a, где d_i,u_a,r_a≥1. Мультимножество значений u_a в группе представим объединением целочисленных интервалов J_{i,t} с положительными числами; интервалы могут повторяться и пересекаться, учитываются все вхождения. Пишем H_{i,t}=max J_{i,t}. Если Σ_i d_i N_i≤M, то
$$
\tau(A,I)\le n+\sum_{a\in A}\omega(r_a)+\sum_{i,t}\pi(H_{i,t}),
$$
где π(x) — число простых ≤x. Для одной группы условие вместимости автоматически, поскольку A состоит из N различных кратных d. Более общая достаточная предпосылка — возможность взять в I попарно непересекающиеся отрезки прогрессий по N_i последовательных кратных d_i.

Доказательство. Отводим в I группам непересекающиеся интервалы длины d_i N_i. Из каждого берём все N_i кратных d_i, получая F размера n. После деления на d_i получаются N_i последовательных целых. Сравним для каждого p^j профиль исходных ядер d_i u_a с профилем F. Если j≤v_p(d_i), в группе с обеих сторон N_i кратных. Иначе положим q=p^{j−v_p(d_i)}. В выбранных частных ≥⌊N_i/q⌋ кратных q. В J длины l их число ≤⌊l/q⌋+1_{max J≥q}. Сумма целых частей ⌊l/q⌋ по J не больше ⌊N_i/q⌋. На любом уровне дефицит группы поэтому ≤#{t:H_{i,t}≥p}. При переходе от d_i u_a к a число требований на каждом уровне p^j возрастает не более чем на #{a:p|r_a}. Применение леммы 1 и суммирование по p дают теорему. □

В частности, если r_a — единицы или произвольные простые степени, ΣH_{i,t}=O(n) и минимальный H_{i,t} стремится к бесконечности, получается 2n+o(n) из π(x)=O(x/log x). Показатели d_i, u_a и r_a не ограничены. Точная величина k_p из леммы 1 позволяет сохранить экономию там, где прогрессия уже покрыла часть внешних множителей.

## 4. Строгая оценка для препятствия из предыдущего отчёта

**Теорема 4.** В обозначениях §3 group-deficit-and-repair.md для семейства
$$
 A=\{3\}\cup\{Pdu:T^{0.65}<P\le T^{0.75},\ P\text{ простое}, T/(2Pd)<u\le T/(Pd)\},\qquad d=2^{\lfloor(\log_2 T)/10\rfloor}
$$
при любом интервале длины max A выполнено
$$\tau(A,I)\le(2-\log(15/13)+o(1))n.$$
Логарифм натуральный.

Доказательство. Положим N=n−1, k_P — число допустимых u для P, H_P=⌊T/(Pd)⌋. По оценке Мертенса для суммы обратных простых L_T=Σ_P1/P→L=log(15/13). Равномерно k_P=T/(2Pd)+O(1), причём минимум k_P≫T^{0.15}. Значит N=(T/(2d))(L+o(1)); число P не превосходит T^{0.75}=o(N). Здесь d≈T^{0.1}; знак ≈ в этом утверждении означает сравнимость с абсолютными константами.

Берём F из N последовательных кратных d, существующих по различности исходных больших модулей. Для всех простых вне диапазона P вклад нехватки от ядер du в лемме 1, как в теореме 3, имеет сумму ≤Σ_P π(H_P)=O(N/log T): имеем H_P≤2k_P+2, H_P≫T^{0.15}. Малый модуль 3 увеличивает оценку не более чем на единицу. Для простого P из указанного диапазона все u≤T^{0.25}·O(1)<P, и исходный показатель P равен единице ровно в k_P строках. К тому же P не делит d. Среди N взятых частных ≥⌊N/P⌋ кратны P. Следовательно, k_p леммы 1 для p=P не больше (k_P−⌊N/P⌋)_+. Поскольку (N/P)/k_P=L+o(1)<1 равномерно, сумма этих величин равна
$$N-\sum_P\lfloor N/P\rfloor=(1-L+o(1))N.$$
Прибавляем N начальных точек, O(N/log T) и одну точку. Получаем требуемое. □

Причина выигрыша — одна и та же прогрессия даёт и полный общий множитель d на каждую строку, и большую часть нужных уровней в частных, и уже учтённые кратные внешних P. Мера потери ≫n log M для независимых назначений относится к другой конструкции и совместима с теоремой 4.

## 5. Перенос произвольных составных частей над меняющимся множеством простых

Пусть S={p₁<⋯<p_s} и q₁<⋯<q_s — первые s простых. Кодируем профиль показателей числом κ(b)=∏ q_i^{v_{p_i}(b)}. Для d=∏q_i^{e_i} определяем D(d)=∏p_i^{e_i}. Имеем D(d)≥d, и d|κ(b) равносильно D(d)|b. Назовём числа над q₁,…,q_s допускаемыми; 1 допускается. Π_X — гистограмма профилей κ(b) для b∈X. Пусть
$$\Delta=\sum_v(\Pi_{[1,M]}(v)-\Pi_I(v))_+.$$
Это также максимум разности количеств по произвольному множеству профилей, поскольку массы гистограмм равны. При s=0 разность нулевая.

**Теорема 5.** Для фиксированного B≥1, равномерно по I и выбору S с s≤(log M)^B, имеем
$$\Delta\le M^{1-1/B+o(1)}.$$
Смысл o(1): для каждого ε>0 при M≥M₀(B,ε) правая часть может быть заменена на M^{1−1/B+ε}. Простые p_i могут быть больше M и не ограничены сверху.

Доказательство. Пусть f — индикатор произвольного множества допустимых профилей. На допускаемых числах по формуле Мёбиуса
$$f(v)=\sum_{d|v}\lambda(d),\qquad
\lambda(d)=\sum_{e|d}\mu(d/e)f(e),\qquad |\lambda(d)|\le2^{\omega(d)}.$$
Обрежем первую сумму при d≤M. Для [1,M] она точна, поскольку κ(b)≤b. Суммы обрезанной функции по двум интервалам различаются не более чем на Σ_{d≤M}2^{ω(d)} по допускаемым d: количества кратных каждого D(d) в двух интервалах одной длины различаются не более чем на один.

Оценим ошибку в сдвинутом интервале. Если κ(b)>M, любой d|κ(b) с d≤M можно домножать по одному простому делителю κ(b)/d до первого m>M. Тогда m|κ(b), M<m≤M q_s и d|m. Для d=1 это даёт хотя бы одного свидетеля. Значит абсолютная ошибка на b не превосходит суммы
$$\sum_{\substack{m|\kappa(b)\\ M<m\le Mq_s}}
\left(1+\sum_{d|m}2^{\omega(d)}\right).$$
Для каждого такого допускаемого m соответствующий модуль D(m)≥m>M, поэтому m служит свидетелем не более чем для **одной** точки I, как бы далеко ни был сдвинут I. Внутренняя сумма равна ∏_{q^e∥m}(1+2e)≤τ₀(m)^2. Итак,
$$\Delta\le\sum_{\substack{d\le M\\ d\text{ допускается}}}2^{\omega(d)}
+2\sum_{\substack{M<m\le Mq_s\\ m\text{ допускается}}}\tau_0(m)^2.$$

Остаётся оценить число допускаемых m≤X=Mq_s. Из стандартной оценки для s-го простого q_s=O(s log(2s)) получаем q_s≤(log M)^{B+o(1)}. Для любого фиксированного σ∈(1−1/B,1) число таких m не больше
$$X^\sigma\prod_{q\le q_s}(1-q^{-\sigma})^{-1}.$$
Логарифм произведения ≤C_σ Σ_{2≤k≤q_s} k^{−σ}=O_σ(q_s^{1−σ})=o(log M). При m≤X верно τ₀(m)=M^{o(1)} равномерно: для каждого ε>0 неравенство e+1≤p^{εe} выполняется для больших p и всех e, а для конечного числа меньших p достаточно постоянного множителя для каждого p. Получаем Δ≤M^{σ+o(1)}. Произвольность σ завершает доказательство, в том числе при B=1. □

**Теорема 6.** Обозначим a_S=∏_{p∈S}p^{v_p(a)}, m_S=#{a:a_S>1}. Тогда
$$\tau(A,I)\le m_S+\sum_{a\in A}\omega(a/a_S)+(s-1)_+\Delta.$$

Доказательство. Для строк a_S>1 назначаем различные точки I с тем же S-профилем, отдельно для каждого профиля и до исчерпания спроса либо предложения. Так как A⊆[1,M], не получили точки u≤Δ строк. Уже выбрано m_S−u точек. Для p∈S на каждом уровне не хватает не более числа неразмещённых строк, делящихся на p. По лемме 1 достаточно не более su дополнительных точек для всех p∈S. Для p вне S хватает #{a:p|a} точек, тоже по лемме 1. Складываем. При S=∅ остаётся обычная оценка через сумму ω. □

**Следствие 6.1.** Если B<3/2 фиксировано, s≤(log M)^B и Σ_a ω(a/a_S)≤n+o(n), то τ≤2n+o(n), равномерно при равномерном остатке в предпосылке. Например, каждое число может включать сколь угодно сложный S-делитель и одну произвольную внешнюю простую степень. Более точно, если n≥M^α и 1−1/B<α, то добавка в теореме 6 равна o(n). Для B<1 достаточно взять B=1.

Доказательство. При M<(2n−1)^3 имеем для B<3/2 показатель 1−1/B<1/3 и sΔ=o(n). При M≥(2n−1)^3 резервируем кратное одного модуля, остальные разбиваем жадно на две метки. Каждая составная метка h≤M^{2/3} имеет ≥2n−1 кратных и получает новую точку. Простые метки добавляем в конце по одному показателю, если текущего произведения не хватает. Бюджет ≤2n−1. Утверждение при n≥M^α следует непосредственно из теорем 5–6. □

Тем самым можно размещать почти все S-части различных исходных чисел на одной точке каждая, даже когда S-части велики, часто одинаковы или имеют сложные взаимные НОД. В этой схеме перенос происходит до образования конфликтов прежнего алгоритма. Предпосылки теоремы 6 относятся к исходным строкам и не дают права применять её с тем же Δ к произвольным оставшимся требованиям после фиксации других точек.

## 6. Где остаётся препятствие

Малый дефект сопоставления **целых** меток с разными точками невозможен без структурного условия. Возьмём n различных нечётных простых в (X,2X], A={2p}, M=max A. В интервале длины M с центром в достаточно большом общем кратном всех 2p (при чётной длине сдвигаем центр на пол-единицы) у каждого 2p>M/2 единственное кратное — эта общая точка. Исходные модули имели n различных представителей в [1,M]; на сдвиге дефицит Холла равен n−1. Сама задача дешева: общая точка содержит все нечётные простые, а двоичный показатель можно дополнить. Так что равномерное o(n) нельзя ожидать от инъективного размещения целых модулей.

Малый общий набор S с одним остаточным простым в среднем тоже не гарантирован. Возьмём три непересекающиеся группы простых в (X,2X], каждая размера t порядка X/log X, и все произведения по одному из каждой группы. Тогда n=t³, M сравнимо с X³. Любой набор из (log M)^B простых пересекает суммарно не больше t²(log M)^B=o(n) вхождений строк, считая каждое вхождение простого отдельно. Значит Σ_a ω(a/a_S)≥3n−o(n). Этот пример отделяет предпосылку теоремы 6 от общей постановки; он сам имеет ограниченный ранг.

Пока нет оценки, которая для любого A разлагала бы непокрытые множители в короткое по суммарной стоимости семейство прогрессий или обеспечивала малую ошибку переноса одновременно с бюджетом в среднем две точки на строку. Следующий конкретный вопрос — выбрать начальные F из нескольких прогрессий и считать реальные дефициты леммы 1 по каждому простому. Теорема 4 показывает, что можно получить линейную экономию уже от покрытия внешних простых. Для прогрессий с пересечениями требуется оценивать C_F по объединению: сложение их отдельных вкладов без поправки неверно.

## 7. Конечные проверки

Ниже приведён код Python 3. На этом этапе пройдены 1680 проверок исправления по различным простым в НОД, 2784 проверки переноса профилей и 306 проверок покрытия прогрессиями. В первом тесте учтены 15334 вхождения составных остатков c с (2n−1)c>M. Во втором максимальное наблюдённое Δ равно 9. Проверялась делимость произведений построенных множеств и соответствующие конечные ограничения. В тестах профилей для второго построения проверялись число неразмещённых строк и итоговая делимость. Значения асимптотических констант и утверждения о произвольном сдвиге следуют из доказательств, не из перебора.

Исходная постановка: https://www.erdosproblems.com/708 . Материалы исследования: https://github.com/redlydi/Erdos708-Research/tree/main/reports .

from collections import Counter
from math import gcd,lcm,prod
from itertools import chain
def fac(x):
    out=Counter()
    j=2
    while j*j<=x:
        while x%j==0:
            out[j]+=1
            x//=j
        j+=1
    if x>1: out[x]+=1
    return out
def split(a):
    h=[1,1]
    for p in sorted(fac(a).elements(),reverse=True):
        i=int(h[0]>h[1])
        h[i]*=p
    return h
def vp(x,p):
    e=0
    while x%p==0:
        e+=1
        x//=p
    return e
def repair(A,I):
    M=max(A)
    b0=next(b for b in I if b%M==0)
    F={b0}
    G={}
    rest=[]
    for a in A:
        if a==M:continue
        for h in split(a):
            if h==1:continue
            if len(list(fac(h).elements()))==1:
                rest.append(h)
                continue
            choices=[b for b in I if b!=b0 and not b%h]
            b=max(choices,key=lambda b:(b in G,len(fac(b)),b))
            if b in G:rest.append(gcd(h,G[b]))
            G[b]=lcm(G.get(b,1),h)
            F.add(b)
    budget=len(F)+sum(len(fac(c)) for c in rest)
    for p,k in Counter(chain.from_iterable(fac(c).keys() for c in rest)).items():
        extra=sorted(set(I)-F,key=lambda b:vp(b,p),reverse=True)[:k]
        F.update(extra)
    assert len(F)<=budget and prod(F)%prod(A)==0
    return sum(1 for c in rest if c>1 and len(list(fac(c).elements()))>1 and (2*len(A)-1)*c>M)
N=C=0
for M in range(6,86):
    for t in (0,1,7,27,83,209,2309):
        for A in [list(range(2,M+1)),sorted({M,*range(M//2+1,M+1)}),sorted({M,*range(2,M,3)})]:
            C+=repair(A,range(t+1,t+1+M))
            N+=1
print("repair tests",N,"large composite residual occurrences",C)
K=0
highest=0
for M in range(2,31):
  for t in [*range(30),209,2309]:

      def key(x): return tuple(vp(x,p) for p in S)
      hist=Counter(map(key,range(1,M+1)))
      target=Counter(map(key,I))

      highest=max(highest,D)
      A=list(range(2,M+1))

      F=set()
      missing=[]

        v=key(a)
        if not any(v):continue

print("profile tests",K,"maximum observed profile discrepancy",highest)
def run_cover(groups,shift):
    A=[d*u*r for d,r,lo,hi in groups for u in range(lo,hi+1)]
    n=len(A)
    M=max(A)
    assert len(set(A))==n and sum(d*(hi-lo+1) for d,r,lo,hi in groups)<=M
    F=set()
    start=shift+1
    for d,r,lo,hi in groups:
        end=start+d*(hi-lo+1)
        F.update(b for b in range(start,end) if b%d==0)
        start=end
    I=range(shift+1,shift+M+1)

    assert len(F)<=bound and prod(F)%prod(A)==0
