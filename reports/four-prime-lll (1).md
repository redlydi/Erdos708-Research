# Проблема Эрдёша №708: четыре различных простых и локальная лемма Ловаса

**Дата:** 25 ноября 2026. **Статус:** исследовательская запись, письменные доказательства из двух ответов Astra 6.2. Нет независимой публикационной экспертизы или Lean-верификации; литературный приоритет не установлен. Общая асимптотика `g(n) ≤ (2+o(1))n` не доказана.

Источник базовой постановки: [REPORT.md](REPORT.md); [задача №708](https://www.erdosproblems.com/708).

## 0. Определения и технический принцип

Пусть `A` — множество `n` различных чисел от 2 до `M=max A`; `I` — `M` последовательных целых. `τ(A,I)` — минимальное число **различных** точек интервала, произведение которых делится на произведение всех членов `A`. Если `0∈I`, достаточно нуля; отрицательные интервалы отражаются. Далее `I` положителен.

**Принцип дополнения простых показателей.** Произведение `M` последовательных положительных целых кратно `M!`: для интервала `[u+1,u+M]` это `M!·binom(u+M,M)`. А `∏_{a∈A}a` делит `M!`, потому что `A⊆{1,...,M}` и все члены различны. Если уже выбранные точки не дают полного показателя простого `ℓ`, среди **не выбранных** точек найдётся ещё кратное `ℓ`; иначе полный интервал не обладал бы нужным показателем. Поэтому каждое оставшееся вхождение простого можно дополнить одной новой точкой (или меньшим числом, если новая точка покрывает несколько вхождений).

## 1. Теорема A: граф ядер малой степени

Пусть каждый модуль имеет вид `a=pqrs` для простых `p<q<r<s`. Назовём `d(a)=qr` его **ядром**. В графе различных ядер два ядра соединены, если имеют общий простой делитель; `Δ` — максимальная степень.

**Теорема A (письменное доказательство, требует независимой проверки).** Существует абсолютное `c>0`, такое что для достаточно большого `M` из

`Δ+1 ≤ c·log M/log log M`

следует `τ(A,I) ≤ 2n−1` для любого интервала `I` длины `M`.

### Лемма A1: запас соседей

Пусть `J` — любые `L` последовательных положительных чисел, а `T` — непустое семейство различных полупростых `ps≤L`, `p≤s`. Для каждого `ps` допустимы точки `J`, кратные `p`. Если `N` — количество точек в объединении, то равномерно по `J` и всему семейству

`N/T ≫ log L/log log L`.

**Доказательство.** Пусть `S` — множество меньших простых `p` в семействе, `x=Σ_{p∈S}1/p` и `D=Σ_{p∈S}⌊L/p⌋`. Поскольку `p≤√L`, при `L≥4` имеем `D≥Lx/2`. Положим `u(b)=#{p∈S:p|b}` для `b∈J`. Тогда `Σu(b)≥D`. Для двух различных `p,p′∈S` имеем `pp′≤L`; их общих кратных в `J` не больше `⌈L/(pp′)⌉≤2L/(pp′)`. Значит, `Σu(b)(u(b)−1)≤2Lx²`. Неравенство Коши даёт

`N ≥ D²/(D+2Lx²) ≫ L·min(x,1)`.

Для каждого `p` возможных `s` не больше `π(L/p)`. Поскольку `L/p≥√L`, оценка Чебышёва `π(y)≪y/log y` даёт `T≪Lx/log L`. Ещё одно применение оценки Чебышёва и частичного суммирования даёт `x≤Σ_{p≤√L}1/p≪log log L`. Деление доказывает лемму.

### Доказательство теоремы A

**Резерв.** Выберем `a₀∈A` и точку `b₀∈I`, кратную `a₀`: она существует, так как `a₀≤M`. **Исключим `a₀` из дальнейших назначений**, а `b₀` запретим остальным модулям.

**Списки через Холла.** Для фиксированного ядра `d=qr` частные от деления кратных `d` в `I` образуют интервал не менее чем из `L=⌊M/d⌋` последовательных целых. Каждый модуль этого ядра соответствует отличному от других `ps=a/d≤L`. Так как `s>√d` и `M≥pds>d^{3/2}`, то `L≥⌊M^{1/3}⌋`. Положим `K=⌈8e(Δ+1)⌉`. При достаточно малой абсолютной константе `c` лемма A1 обеспечивает для каждого подсемейства размера `T` по меньшей мере `(K+1)T` возможных точек. Исключение `b₀` удаляет не более одной, оставляя не менее `KT`. Применяя теорему Холла к `K` копиям каждого модуля, получаем для каждого оставшегося модуля список `K` точек, кратных `dp`, причём **списки разных модулей одного ядра не пересекаются** и `b₀` отсутствует во всех списках.

**Локальная лемма Ловаса.** Независимо выбираем для каждого модуля по одной равновероятной точке его списка. Плохое событие: два модуля с разными, но смежными ядрами выбирают одну и ту же **конкретную** точку пересечения их списков. Вероятность одного такого события `K^(−2)`. Каждый модуль участвует не более чем в `KΔ` плохих событиях: для каждой его точки и каждого соседнего ядра лишь один модуль соседнего ядра может иметь эту точку в списке. Следовательно, событие зависит не более чем от `2KΔ` других событий. Поскольку `e(2KΔ+1)/K²<1`, симметричная локальная лемма Ловаса гарантирует выбор без плохих событий. У модулей, назначенных в одну точку, ядра попарно взаимно просты.

**Учёт.** Пусть в одной точке `b` оказалось `t` модулей. Произведение их попарно взаимно простых ядер `D=∏d_i` делит `b`. Возьмём модуль с минимальным средним простым `q_i` во всей группе. Его внешний простой `p_i<q_i` не делит ни одно ядро группы, а `p_i d_i | b`; следовательно, `D p_i | b`. Эта одна точка покрывает `2t+1` из требуемых `4t` простых вхождений. Не более `2t−1` оставшихся вхождений дополняем по техническому принципу из §0. Цена группы ≤`2t` точек. Вместе с резервом: `1+2(n−1)=2n−1`. Для `n=1` достаточно резерва. □

**Предел метода.** Если `A` состоит из всех четвёрок из `t` разных простых, то любой выбор пары-ядра для каждой четвёрки даёт граф `H` на простых с хотя бы `C(t,4)/C(t−2,2)=t(t−1)/12` рёбрами. У одной вершины степень как минимум `(t−1)/6`, а все ядра, содержащие этот простой, образуют клику в графе ядер. Значит, `Δ≥(t−1)/6−1`; степень может быть слишком большой для теоремы A. Это препятствие **к методу**, не нижняя оценка `τ`.

## 2. Лемма B: критерий фактических пересечений

Зарезервируем полное кратное `b₀` одного модуля `a₀∈A` и удалим `a₀` из последующих задач. Каждое другое `a=pqrs` разобьём на две пары различных простых: `a=h_{a,1}h_{a,2}`. Каждое вхождение пары рассматривается отдельно: всего `2(n−1)` задач `i` с метками `h_i`. Для каждой выберем непустой список `V_i` из точек `b∈I`, для которых `h_i|b` и `b≠b₀`.

**Лемма B.** Если для каждой задачи `i`

`Σ_{j≠i, gcd(h_i,h_j)>1} |V_i∩V_j|/(|V_i||V_j|) ≤ 1/8`,

то `τ(A,I)≤2n−1`.

**Доказательство.** Выберем независимо и равномерно по одной точке `B_i∈V_i`. Для задач `i,j` с `gcd(h_i,h_j)>1` плохое событие `E_ij` состоит в совпадении `B_i=B_j`; его вероятность `P_ij=|V_i∩V_j|/(|V_i||V_j|)`. Нулевые события опускаем; остальным назначим `x_ij=2P_ij`, причём `0<x_ij≤1/4`. События с непересекающимися парами индексов независимы. Для соседей любого `E_ij` сумма их `x` не больше `2(1/8+1/8)=1/2`, поэтому `∏_{F~E_ij}(1−x_F)≥1−Σ_{F~E_ij}x_F≥1/2`. Следовательно, `x_ij∏(1−x_F)≥P_ij`. Асимметричная локальная лемма Ловаса обеспечивает выбор без плохих событий.

В каждой занятой точке назначенные ей метки попарно взаимно просты и все делят эту точку, следовательно, **произведение** этих меток делит точку. Произведение по всем различным занятым точкам, вместе с резервом `b₀`, кратно `∏A`. Всего точек не больше `2(n−1)+1=2n−1`. □

**Особенность:** критерий оценивает реальный риск пересечения списков, а не количество потенциально соседних ядер; одинаковые пары тоже допустимы при достаточно больших списках.

## 3. Теорема C: все четыре простых одного масштаба

**Теорема C.** Зафиксируем `C>1`. Для достаточно большого `X` (в зависимости только от `C`) пусть `A` — **любое** множество различных произведений четырёх различных простых из `[X,CX]`. Тогда для каждого интервала `I` длины `M=max A` имеем

`τ(A,I) ≤ 2n−1`.

Допускается семейство всех четвёрок и произвольно большая степень графа ядер. Разбиение каждого модуля на две пары допускается любое.

**Доказательство.** Резервируем `a₀`, `b₀` как в лемме B и разбиваем остальные модули на две пары; для каждого вхождения `h_i` возьмём **полный** список всех кратных `h_i` в `I`, кроме `b₀`. Пусть `t` — число различных простых, используемых в `A`. По оценке Чебышёва `t≤π(CX)=O_C(X/log X)`. Также `X⁴≤M≤C⁴X⁴` и `X²≤h_i≤C²X²`, поэтому равномерно по сдвигу

`|V_i|≥⌊M/h_i⌋−1 ≫_C X²`.

Зафиксируем `h_i=uv`. В сумме леммы B возможны только два типа конкурирующих пар.

1. **Та же пара `uv`.** Не более `C(t−2,2)=O(t²)` различных модулей содержат оба простых `u,v`; каждый модуль создаёт не более одной задачи с меткой `uv`. При одинаковых полных списках риск совпадения `1/|V_i|=O_C(X^(−2))`. Общий вклад `O_C(t²/X²)`.

2. **Ровно один общий простой.** Для таких `h_j` НОК с `h_i` — произведение трёх разных простых, не меньше `X³`. Число кратных их НОК в `I` не больше `⌈M/НОК⌉=O_C(X)`, поэтому риск конкретной пары `O_C(X^(−3))` после деления на размеры списков. Каждый из `u,v` встречается не более чем в `C(t−1,3)=O(t³)` модулях; в любом модуле конкретный простой принадлежит ровно одной из двух задач. Поэтому конкурирующих задач `O(t³)`, суммарный вклад `O_C(t³/X³)`.

Левая часть критерия для каждой задачи не больше

`O_C(t²/X² + t³/X³)=O_C(1/log² X)`, 

что меньше `1/8` при достаточно большом `X`. Лемма B доказывает теорему. □

### Почему это действительно усиление

Возьмём все четвёрки из простых `[X,2X]`. По теореме о распределении простых их количество `t` имеет порядок `X/log X`. Как показано в §1, при **любом** выборе одного ядра на каждую четвёрку максимальная степень графа ядер как минимум порядка `t`, а `log M/log log M` лишь логарифмического порядка. Теорема A неприменима, однако теорема C обеспечивает `2n−1`.

## 4. Статус и направления проверки

- Теоремы A и C имеют приведённые выше письменные доказательства. Лемма B является самостоятельным достаточным критерием.
- Проверка старого кода репозитория, даже если успешна, **не доказывает** эти новые утверждения.
- Не проводились формализация Lean, машинная сертификация общих доказательств, независимое рецензирование или проверка литературного приоритета.
- Общая асимптотика `g(n)≤(2+o(1))n` **остаётся открытой**.

**Следующая математическая задача:** снять требование сравнимости четырёх простых. Для каждой четвёрки нужно выбрать одно из трёх разбиений на две пары и добиться малого фактического пересечения списков. Для полных списков верхняя оценка отдельного слагаемого леммы B задаётся выражением

`⌈M/lcm(h_i,h_j)⌉ / ((⌊M/h_i⌋−1)(⌊M/h_j⌋−1))`

при положительных знаменателях. Особенно труден случай нескольких сильно разнесённых диапазонов простых.
