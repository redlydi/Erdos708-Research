# Эрдёш — Сураньи №708. Одновременное покрытие уровней при M ≥ n^{3/2+ε}

Исследовательский отчёт от 25 ноября 2026 г. Доказательства письменные. Универсальная асимптотика для всех M остаётся открытой в этой работе. Литературный приоритет не устанавливался.

## 1. Главный результат

Пусть A состоит из n различных натуральных чисел ≥2, M=max A, I — любые M последовательных целых, C_X(q)=#{x∈X:q|x}. Обозначим через H(A,I) наименьшее число точек B⊆I, для которых C_B(p^j)≥C_A(p^j) при всех простых p и всех j≥1. Достаточно проверять степени ≤M. Точка 0 кратна каждому q. Всегда C_I(q)≥⌊M/q⌋≥C_A(q). Отсюда H определено. Доминирование всех уровней влечёт делимость произведений, так что τ≤H.

**Теорема.** Для каждого фиксированного ε>0 есть c=c(ε)>0, для которого при M≥n^{3/2+ε} равномерно по A и сдвигу I выполнено
$$ H(A,I)\le 2n+O_\varepsilon(n^{1-c}). $$
Ограничений на показатели, число простых или их повторение нет. При M≥(2n−1)^3 достаточно 2n−1. Первая оценка асимптотическая; её константа не утверждается равномерной по ε→0.

**Тождество для предложенного критерия.**
$$ H(A,I)=\min_{F\subseteq I}\left(|F|+\sum_p\max_{j\ge1}(C_A(p^j)-C_F(p^j))_+\right). $$
В самом деле, при фиксированном F обозначим максимум для p через k_p. Берём k_p точек из I∖F с наибольшими p-показателями, либо весь остаток. На уровне j число кратных p^j после дополнения равно min(C_I(p^j),C_F(p^j)+k_p) или больше при объединении с выборами по другим простым. Оно ≥C_A(p^j). Можно считать показатель нуля бесконечным. Это доказывает H≤правой части. Оптимальное множество для H даёт обратное неравенство. В частности, теорема отвечает на вопрос именно о предложенном критерии.

## 2. Блоки, сохраняющие целые простые степени

Назовём q=p^{v_p(a)} при p|a атомом числа a. Запись t∥a в этом отчёте означает унитарную делимость: t|a и gcd(t,a/t)=1. Унитарные делители — произведения подмножеств атомов. Два числа h,k называем совместимыми, если на общих простых их показатели равны. Тогда gcd(h,k) — унитарный делитель обоих.

Жадно разложим a в два блока: по невозрастанию **значений атомов** умножаем очередным атомом меньший текущий блок. Если q₀ — последний атом блока h, перед его добавлением другая сторона была ≥h/q₀. Поэтому h²≤a q₀≤M q для каждого атома q блока. Если в h как минимум два атома, q₀≤√h и h≤M^{2/3}. Назовём такой блок смешанным. Свойство h²≤Mq наследует каждый нетривиальный унитарный делитель h, для каждого из своих атомов.

При M≥(2n−1)^3 выбираем кратное одного полного модуля, остальные разбиваем описанным способом. Каждому смешанному блоку можно дать свою новую точку: кратных у него ≥2n−1. Блоки из одного атома откладываем. Для любого p и любого j число ещё не покрытых строк на этом уровне не больше числа отложенных атомов с основанием p. Действительно, каждый исходный p-показатель целиком принадлежал одному блоку, а выбранные для размещённых блоков точки различны. По тождеству §1 расход ≤1+2(n−1). Именно сохранение степеней целиком позволяет сделать вывод о H.

Далее M<(2n−1)^3; достаточно рассматривать большие n. Обозначение M^{o(1)} используется для оценок, равномерных по всем целым числам ≤M, всем семействам и сдвигам. В частности τ₀(h), 2^{ω(h)}=M^{o(1)}, где τ₀ — число делителей, ω — число различных простых. Элементарное доказательство: для каждого η>0 при достаточно большом p имеем e+1≤p^{ηe} для всех e≥1; для каждого из конечного числа остальных простых достаточно фиксированного дополнительного множителя. Перемножаем. Поскольку M≤8n³, эти факторы равны также n^{o(1)}.

## 3. Извлечение часто встречающихся унитарных делителей

Заранее сделаем жадное разбиение всех исходных строк. Пусть D — множество всех унитарных делителей >1 всех исходных **смешанных** жадных блоков. В частности, D замкнуто относительно взятия нетривиальных унитарных делителей; каждый d∈D не больше M^{2/3}. Выберем W=M^{1−δ}, 0<δ<1, конкретное δ будет задано ниже.

Пока среди оставшихся строк имеется d∈D с
$$d\,r(d)\ge W,\qquad r(d)=\#\{a\text{ осталось}:d\parallel a\},$$
выбираем **наименьшее по величине** такое d. Удаляем сразу все строки, для которых d∥a. Это группа G_d размера N_d; каждой строке в ней даём метки d и m=a/d. Метку d будем называть основной, m — дополнительной. Одно и то же d не извлекается дважды. В оставшихся после остановки строках используем изначальные жадные блоки; назовём их конечными. Единицы выбрасываем, одноатомные метки откладываем, остальные будем размещать. В каждой строке сохранились два взаимно простых блока и все показатели исходного числа.

Два следствия, важные для количественной оценки:
$$\sum_d\frac1d\le\frac{n}{W},\qquad m\le \frac M d\le X:=\frac{Mn}{W}=nM^\delta.$$
Первое следует из W/d≤N_d и непересечения групп. Внутри каждой группы дополнительные метки **различны**, поскольку исходные числа различны. Каждая размещаемая метка h не больше
$$L=\max(M^{2/3},X).$$

## 4. Сумма НОД и роль порядка извлечения

Обозначим через E сумму gcd(h,k) по неупорядоченным парам **вхождений** размещаемых меток разных числовых значений, совместимых и с gcd(h,k)>1. Докажем
$$ E\ll nM^{o(1)}\left(W+\frac{Mn}{W}\right). \tag{1} $$

**Пары с дополнительной меткой.** Фиксируем произвольное вхождение z. В группе G_d дополнительные значения m различны и ≤M/d. Поэтому
$$
\sum_{m\in G_d}\gcd(z,m)
\le\sum_{t|z}t\left\lfloor\frac{M}{dt}\right\rfloor
\le\tau_0(z)M/d .
$$
Здесь сумма слева идёт по дополнительным меткам группы, а не по её исходным модулям. Суммирование по группам даёт ≤τ₀(z)Mn/W. Суммируем по не более 2n вхождениям z; возможный двойной учёт безопасен.

**Основные и конечные метки.** Упорядочим основные по времени извлечения, за ними поставим конечные. Учитываем для фиксированного основного вхождения z=d только более поздние группы и конечные метки. Вхождения внутри G_d численно одинаковы и в E не входят. Для совместимого более позднего k с нетривиальным t=gcd(d,k) имеем t∥d и t∥k. Равенство t=d невозможно: тогда d был бы унитарным делителем исходной строки k, и эта строка была бы удалена уже при извлечении d. Следовательно, 1<t<d и t∈D. На момент извлечения d выполнялось t r(t)<W по минимальности d. Все учитываемые далее строки тогда ещё присутствовали. Поэтому суммарный вклад по данному t для фиксированного вхождения d не больше 2t r(t)<2W: у каждой строки ≤2 меток. Число возможных t не превосходит τ₀(d).

Если и z, и k конечные, t=gcd(z,k)>1 для совместимой пары снова лежит в D, и теперь t r(t)<W по условию остановки, в том числе если t=z. Тот же подсчёт даёт ≤2Wτ₀(z) на одно вхождение. Сложение с первым случаем доказывает (1). Условие совместимости существенно: обычный НОД может отделять только часть степени и тогда унитарности нет.

## 5. Точные списки и зависимый выбор для равных меток

Для каждого размещаемого h берём список
$$V_h=\{b\in I:h\mid b,\ \gcd(h,b/h)=1\}.$$
Это прогрессия кратных h с исключением кратных hp для p|h. Если h и k несовместимы, V_h∩V_k пусто. Положим μ(h) равным числу вхождений h. Так как разбиение унитарно и h>1, одна строка даёт h не более одного раза; все эти строки уже имели точный профиль h. Значит μ(h)≤#{1≤a≤M:h∥a}.

Включение–исключение по простым h даёт, равномерно по сдвигу,
$$|V_h|=\frac M h\prod_{p|h}(1-1/p)+O(2^{\omega(h)}),\qquad
\mu(h)-|V_h|\le 2^{\omega(h)}. \tag{2}$$
Для второго неравенства сравниваем два интервала одной длины: количества кратных каждого фиксированного модуля отличаются не более чем на один. Формулы верны и для интервала с нулём. Когда M/L≥n^κ для фиксированного κ>0, получаем |V_h|≥(M/h)M^{−o(1)}, поскольку произведение в (2) ≥2^{−ω(h)}. Для каждого переполненного списка опускаем μ(h)−|V_h| задач. Число переполненных значений не превосходит 2n/min_h|V_h|, поэтому всего опущено
$$O\bigl(n (L/M) M^{o(1)}\bigr). \tag{3}$$
Если задач нет, соответствующие суммы нулевые.

Остальным вхождениям одного значения h назначаем **различные** элементы V_h равномерной случайной инъекцией. Для разных значений инъекции независимы. Поэтому в паре разных типов каждое назначение имеет равномерную маргинальную вероятность; для вероятности совпадения имеем
$$P_{hk}=\frac{|V_h\cap V_k|}{|V_h||V_k|}
\le M^{o(1)}\left(\frac{\gcd(h,k)}M+\frac{hk}{M^2}\right). \tag{4}$$
Числитель ≤M/НОК(h,k)+1. Совпадение взаимно простых меток разрешаем: они не дублируют ни один p-уровень. Совпадений равных меток нет. По (1) и (4) математическое ожидание числа конфликтующих пар вхождений с общим простым не превосходит
$$nM^{o(1)}\left(\frac WM+\frac nW+\frac{n L^2}{M^2}\right). \tag{5}$$
Совпадения в больших группах здесь подсчитаны с запасом. Для существования назначения достаточно первого момента.

## 6. Завершение доказательства теоремы

Положим e=min(ε,1/4), δ=e/20. В рассматриваемом диапазоне n^{3/2+ε}≤M<(2n−1)^3≤n⁴ при больших n. Имеем
$$\frac{L}{M}\le \max\{n^{-1/2-e/3},\ n^{-1/2-e+4\delta}\}
\le n^{-1/2-e/3}.$$
Кроме того, W/M=M^{-δ}≤n^{-δ}, n/W≤n^{-1/2-e+4δ}. Поэтому (3) и (5) ограничены O_ε(n^{1−δ+o(1)}). Найдётся назначение с не большим числом конфликтующих пар. Опустим обе задачи каждой такой пары; вместе с переполнением это O_ε(n^{1−δ+o(1)}) смешанных задач. В каждой занятой точке оставшиеся метки попарно взаимно просты.

Возьмём за F все оставшиеся занятые точки. Для фиксированного p на каждом уровне p^j любая исходная строка, требующая этот уровень, имела его целиком в одной метке. Если эта метка размещена, её точку можно засчитать: две размещённые метки, содержащие p, стоят в разных точках. Дефицит на любом уровне по p поэтому не больше числа неразмещённых меток, делящихся на p. Сумма максимумов оценивается числом отложенных одноатомных меток плюс Σω(h) по опущенным смешанным. Для последних ω(h)≤log₂M. Число занятых точек плюс число одноатомных меток не превышает 2n. Добавка составляет O_ε(n^{1−δ+o(1)} log M). Можно, например, взять c=e/40. Вместе с кубическим диапазоном из §2 это завершает доказательство.

## 7. Что остаётся при M ≥ n^{1+ε}

В диапазоне n^{1+ε}≤M≤8n³ та же процедура с e=min(ε,1/4), δ=e/20 даёт M/L≥n^{κ(ε)} и W/M+n/W≤n^{−κ'(ε)} для некоторых положительных κ,κ′. Формулы (1)–(4) сохраняются. Если НОК(h,k)≤M, слагаемое hk/M² в (4) не превосходит gcd(h,k)/M. Поэтому число таких плохих пар в среднем O_ε(n^{1−c'(ε)}); опускание их концов и переполнений стоит o(n), даже с учётом ω.

Остаются только **совместимые разные метки с общим простым, НОК>M и единственной общей точкой в I**. В каждой такой паре есть дополнительная метка m=a/d из извлечённой группы. Действительно, основные и смешанные конечные метки удовлетворяют z²≤Mq для каждого своего атома q (§2 и выбор D). Две совместимые метки этих типов с общим атомом q удовлетворяют НОК≤hk/q≤M.

Более точно, по оставшимся совместимым потенциальным парам с НОК>M можно суммировать точную величину
$$J=\sum_{i<j}\frac{\mathbf1_{V_{h_i}\cap V_{h_j}\ne\varnothing}}{|V_{h_i}||V_{h_j}|},$$
где учитываются лишь разные значения с НОД>1 после отсечения переполнений. Оценка J=o(n/log M) достаточна для целевой асимптотики в этом диапазоне. Это достаточный критерий; его равномерная малость не доказана.

**Как учесть совместное исправление в многократной встрече.** После опускания концов конфликтов с НОК≤M рассмотрим s≥1 оставшихся меток в одной точке b. Обозначим через m_p число этих меток, содержащих p. На всех них показатель p одинаков, так как списки точные. Утрата на любом уровне p^j не больше (m_p−1)_+, тогда как экономия составляет s−1 точек. Поэтому допустима следующая подписанная поправка в верхней оценке:
$$R_b=\sum_p(m_p-1)_+-(s-1).$$
Это локальный расчёт верхней оценки, отдельные уровни из разных групп могут дополнительно компенсировать друг друга. Доказательство: к стоимости одной точки добавляем по m_p−1 одноатомных исправлений при m_p>0 и вычитаем s исходных мест. В двудольном графе «метки — простые делители» это R_b=β_b−c_b+1, где β_b — цикломатическое число, c_b — число компонент. Например, любое число меток с единственным общим простым и непересекающимися прочими носителями даёт ноль. Это объясняет, почему крупная сумма попарных вероятностей ещё не опровергает критерий. После удаления вышеописанного малого числа задач достаточно получить сумму R_b≤o(n), с учётом стоимости удалений. Для произвольного назначения это не доказано.

Кроме немедленного диапазона M≤(2+o(1))n, где достаточно всего I, оценки этого отчёта не закрывают в общем виде последовательности с M≤n^{3/2+o(1)}. В частности, при M/n, ограниченном константой >2, даже извлечение с n≪W≪M неприменимо.

## 8. Разделение критерия и исходной задачи

Для сколь угодно больших ℓ возьмём ℓ нечётных простых p₁<⋯<p_ℓ с p_ℓ²<2p₁² (они существуют, например, по теореме о распределении простых в интервалах (x,1.1x)). Пусть A — все p_i p_j, i<j, n=ℓ(ℓ−1)/2, M=max A. Поместим в центр интервала длины M число b₀=∏p_i^{ℓ−1}=∏A. Тогда τ=1. Всякая другая точка b=b₀+t удовлетворяет 0<|t|≤M/2<p₁² и делится максимум на один из наших простых: иначе их произведение делило бы t. Каждый p_i должен встретиться в ℓ−1 различных точках. С центром нужно хотя бы 1+ℓ(ℓ−2)=2n−ℓ+1 точек, без центра ≥2n. Нижняя граница достигается: у каждого p_i имеется ещё не меньше ℓ−2 кратных вне центра по C_I(p_i)≥C_A(p_i), и множества этих точек для разных i не пересекаются. Итак,
$$\tau(A,I)=1,\qquad H(A,I)=2n-\ell+1.$$
Конструкция использует семейство всех пар простых из классической нижней оценки Эрдёша–Сураньи; выбор показателей в центре здесь предназначен для разделения двух целевых функций. Это контрпример к переносу хорошей индивидуальной оценки τ на H. Это не контрпример к H≤(2+o(1))n.

## 9. Аудит материалов и воспроизводимые проверки

Из последнего отчёта использована конструкция дополнения по максимуму дефицитов; её доказательство приведено заново в §1. Жадная оценка из двух предыдущих отчётов независимо выведена в §2 с изменёнными атомами. Разбиение обычного списка простых с кратностями могло разделить p^e между двумя блоками и само по себе не доказывало доминирование уровней. Например, два различных числа с показателями p, равными 1, могут покрыть произведение p² без единой точки, кратной p². В точных списках зависимый выбор для одинаковых типов устраняет потери от самопересечений, а (2) учитывает возможность нехватки точек. В 635 малых задачах обе стороны тождества минимума вычислены полным перебором. Последний тест проверяет конструкцию §8. Эти вычисления не проверяют асимптотический порог, который следует из доказательства.

### Код

```python
from collections import Counter, defaultdict
from functools import lru_cache
from itertools import combinations
from math import gcd, lcm, prod
from random import Random

@lru_cache(None)
def atoms(x):
    answer = []
    p = 2
    while p*p <= x:
        q = 1
        while x % p == 0:
            x //= p
            q *= p
        if q > 1:
            answer.append((p, q))
        p += 1
    if x > 1:
        answer.append((x, x))
    return tuple(answer)

def unitary(d, x):
    return x % d == 0 and gcd(d, x//d) == 1

def split(x):
    h = [1, 1]
    for _, q in sorted(atoms(x), key=lambda t: -t[1]):
        h[int(h[0] > h[1])] *= q
    return h

def levels(A):
    out = Counter()
    for a in A:
        for p,q in atoms(a):
            while q > 1:
                out[p,q] += 1
                q //= p
    return out

def missing(Alevels, F):
    k = Counter()
    for (p,q), target in Alevels.items():
        k[p] = max(k[p], target-sum(b%q == 0 for b in F))
    return k

def compatible(h,k):
    g = gcd(h,k)
    return unitary(g,h) and unitary(g,k)

def solve(A, shift, W, rng):
    M = max(A)
    I = range(shift+1,shift+1+M)
    base = {a:split(a) for a in A}
    D = set()
    for pair in base.values():
        for h in pair:
            if len(atoms(h))<2:
                continue
            ds = [1]
            for _,q in atoms(h):
                ds += [x*q for x in ds]
            D.update(ds[1:])
    remaining = set(A)
    tasks = []
    groups = 0
    while remaining:
        for d in sorted(D):
            rows = {a for a in remaining if unitary(d,a)}
            if rows and len(rows)*d >= W:
                break
        else:
            break
        for a in rows:
            tasks.extend([(d,"base",groups),(a//d,"quot",groups)])
        remaining -= rows
        groups += 1
    for a in remaining:
        tasks.extend((h,"final",groups) for h in base[a])
    lists = defaultdict(list)
    leftover = []
    for h,role,idx in tasks:
        if len(atoms(h)) >= 2:
            lists[h].append((role,idx))
        elif h>1:
            leftover.append(h)
    for h in lists:
        for k in lists:
            if h<k and gcd(h,k)>1 and compatible(h,k):
                if any(r!="quot" for r,i in lists[h]) and any(r!="quot" for r,i in lists[k]):
                    assert lcm(h,k)<=M
    assigned = defaultdict(list)
    shortages = 0
    for h,occ in lists.items():
        V = [b for b in I if unitary(h,b)]
        diff = len(occ)-len(V)
        assert diff <= 2**len(atoms(h))
        for b in rng.sample(V,min(len(V),len(occ))):
            assigned[b].append(h)
        leftover.extend([h]*max(diff,0))
        shortages += max(diff,0)
    F = set()
    conflicts = 0
    for b,hs in assigned.items():
        keep = []
        for h in hs:
            if any(gcd(h,k)>1 for k in keep):
                leftover.append(h)
                conflicts += 1
            else:
                keep.append(h)
        if keep: F.add(b)
    target = levels(A)
    costs = missing(target,F)
    assert sum(costs.values()) <= sum(len(atoms(h)) for h in leftover)
    before = len(F)
    for p,k in costs.items():
        def value(b):
            if b==0: return M.bit_length()+1
            e=0
            while b%p==0:
                b//=p
                e+=1
            return e
        F.update(sorted(set(I)-F,key=value,reverse=True)[:k])
    assert all(x<=0 for x in missing(target,F).values())
    assert len(F)<=before+sum(costs.values())
    return groups, shortages, conflicts

rng = Random(708)
totals = [0]*3
count = 0
for M in (24,45,72,90,120,180,240,360):
    for shift in (-2*M,-M//2,0,13,119,2309,30029):
        for mode in range(3):
            A = set(range(2, M+1)) if mode==0 else ({a for a in range(2,M+1) if a%3==0} if mode==1 else set(rng.sample(range(2,M),M//5)))
            A.add(M)
            for W in (max(2,M//5),3*M//4,2*M):
                vals = solve(A,shift,W,rng)
                totals = list(map(sum,zip(totals,vals)))
                count+=1
print("construction tests, groups, shortages, rejected collisions:",count,*totals)
cases=0
for M in range(2,9):
    for maskA in range(1<<(M-2)):
        A=[M]+[i+2 for i in range(M-2) if maskA>>i&1]
        target=levels(A)
        for shift in (-M//2,0,1,11,209):
            I=range(shift+1,shift+M+1)
            best=M
            bestcover=M
            for bits in range(1<<M):
                F=[b for i,b in enumerate(I) if bits>>i&1]
                k=sum(missing(target,F).values())
                best=min(best,len(F)+k)
                if k==0: bestcover=min(bestcover,len(F))
            assert best==bestcover
            cases+=1
print("exact minimum identities:",cases)
P=[101,103,107,109,113,127,131]
A=[p*q for p,q in combinations(P,2)]
M=max(A)
b0=prod(P)**(len(P)-1)
I=range(b0-M//2,b0-M//2+M)
assert b0%prod(A)==0
assert max(sum(b%p==0 for p in P) for b in I if b!=b0)==1
print("separation n, product minimum, level minimum:",len(A),1,1+sum(missing(levels(A),[b0]).values()))
```
