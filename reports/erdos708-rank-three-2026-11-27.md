# Эрдёш–Сураньи №708. Совместное покрытие крайних диапазонов простых

27 ноября 2026. Письменное доказательство с классическими аналитическими входами. Универсальная оценка для полного произведения остаётся открытой. Литературный приоритет не устанавливался.

## 1. Результат

Пусть $J=[1,M]\cap\mathbb Z$, $A\subseteq[2,M]$, $|A|=n$, $M=\max A$, а $I$ — любой интервал из $M$ последовательных положительных целых. Для множества простых $D$ обозначим через $\tau_D$ наименьшее число различных точек $B\subseteq I$, для которых $\sum_B v_p\ge\sum_A v_p$ одновременно при всех $p\in D$. Пишем $t_+=\max(t,0)$.

**Теорема.** Если $|S|=M^{o(1)}$ (включая также пустое или ограниченное множество) и
$$D=S\cup\{p:M^{1/4}<p\le M\},$$
то $\tau_D\le 2n+o(M)$. Погрешность равномерна по сдвигу, источнику и выбору $S$ при заданной субстепенной верхней границе на $|S|$. При $M=\Theta(n)$ остаток равен $o(n)$. Можно выбирать $S$ после выбора $A,I$. Теорема относится к исходным суммарным показателям. Один набор точек оплачивает обе группы простых. При $M=3n$ она не накладывает ограничений на сам источник.

**Следствие о локализации.** Зафиксируем $\delta>0$. Существуют $c=c(\delta)\in(0,1/4)$ и $M_0$ со следующим свойством. Если при $M=3n\ge M_0$ выполнено $\tau>(2+\delta)n$, то для **любого оптимального двойственного вектора** с $0\le w_p\le1$
$$\sum_{M^c<p\le M^{1/4}}\frac{w_p}{p-1}\ge\delta/6.$$
Такие векторы существуют. Доказательство не даёт эффективного значения $c$. В нормировке $\delta n$ константа $1/6$ оставляет запас на округление и ошибки переноса.

## 2. Прямая LP для делимости произведения

Дробная релаксация минимизирует $\sum_I y_b$ при $0\le y_b\le1$ и $\sum_I v_p(b)y_b\ge\sum_A v_p$ для $p\in D$, $p\le M$. Она допустима, поскольку каждый уровень $p^j$ встречается в $I$ хотя бы $\lfloor M/p^j\rfloor$ раз. Её двойственный оптимум есть максимум
$$\Phi(w)=\sum_A X_w-\sum_I(X_w-1)_+,\qquad X_w(t)=\sum_{p\in D} w_pv_p(t).$$
Это получается устранением множителей ограничений $y_b\le1$. Цену больше единицы можно уменьшить до единицы: на всех кратных этого простого штраф остаётся в линейной части, а суммарный показатель в $I$ не меньше исходного. Вершина исходного допустимого многогранника имеет не более $\pi(M)$ строго дробных координат по линейной независимости соответствующих столбцов. Округление вверх даёт целый допустимый набор стоимостью не более $\max\Phi+\pi(M)$.

Поточечное неравенство $1_A X\le 2\,1_A+(X-2)_+$ и $\sum_I X\ge\sum_J X$ дают
$$\Phi(w)\le 2n+\sum_I\min(X,1)-\sum_J\min(X,2).\tag{1}$$
Далее доказывается сравнение двух последних сумм с ошибкой $o(M)$.

## 3. Сертификат для трёх различных больших простых

Сначала допустим произвольные цены на простых $p\le y$, где $y=M^{o(1)}$, и произвольные цены на $Q\subseteq(M^{1/4},M]$. Обозначим через $s(t)$ полную нагрузку по первой группе, а для второй каждое вхождение считаем один раз. Это меняет любую из ограниченных средних в (1) на $o(1)$: доля точек с $p^2\mid t$ хотя бы для одного $p\in Q$ не больше $\sum_{p>M^{1/4}}p^{-2}+\pi(M)/M=o(1)$ для обоих интервалов. Так мы учитываем и сдвиги с аномально высокими показателями.

Упорядочим $Q$ по возрастанию. При добавлении метки $q\mid t$ обозначим через $V$ суммарную цену уже присутствующих предшественников. Приращение $\min(s+V,L)$ при добавлении $w_q$ есть интеграл индикатора $V<L-s-z$ по $0<z<w_q$; точки равенства несущественны. Положим $u=1-s-z$. При $u<0$ положим $P=0$. При $u\ge0$ определим
$$k=\#\{p\in Q:p<q,\ p\mid t,\ p^2q\le M,\ w_p>u\},\qquad P=1-k+\binom{k}{2}.$$
Для **любой** целевой точки $1_{V<u}\le P$: при $V<u$ имеем $k=0$, а при остальных значениях $P\ge0$. При $u<0$ обе части равны нулю.

На канонической точке $t\le M$ с $q\mid t$ присутствуют не более двух предшественников, поскольку четыре различных простых из $Q$ имеют произведение больше $M$. Поэтому $P\in\{0,1\}$. Если $u\ge0$ и $V>u+1$, присутствуют ровно два предшественника $p<r$ и обе цены превышают $u$, поскольку каждая не больше единицы. Имеем $p^2q\le prq\le t\le M$. Значит, $k=1$ или $2$, так что $P=0$. Для почти всех $z$ на канонических точках, следовательно, $P\le 1_{V<u+1}$, в том числе при $u<0$.

Построим функцию
$$F(t)=\min(s(t),1)+\sum_{q\in Q,\ q\mid t}\int_0^{w_q}P(t,q,z)\,dz.$$
Для нагрузки $X'$ с однократными большими метками доказано
$$\min(X',1)\le F\quad\text{на }I,\qquad F\le\min(X',2)\quad\text{на }J.$$
Во втором неравенстве исходный член $\min(s,1)\le\min(s,2)$. Это сертификат для произвольных действительных цен, включая разные цены на каждом простом.

## 4. Почему среднее сертификата переносится при любом сдвиге

После раскрытия $P$ каждый член имеет вид $f(s(t))1_{d\mid t}$ c коэффициентом-функцией абсолютной величины не более единицы (или ограниченной абсолютной константой после группировки). Возможны $d=1,q,pq,prq$. В тройке $p<r<q$ и $r^2q\le M$, поэтому $prq\le M$. У фиксированного $d$ ограниченная кратность, так как $q$ — наибольший простой. Даже когда сам сдвиг огромен, неконтролируемые модули $d>M$ не появляются.

Приведём детали переноса, чтобы сделать явной равномерность по коэффициентам.

1. На интервале из $H\ge M^\eta/2$ точек для любого фиксированного $\eta>0$ распределение всех показателей при $p\le y=M^{o(1)}$ отличается на $o(1)$ в полной вариации от независимых геометрических показателей с хвостом $p^{-j}$. Вот вывод из основной леммы решета. Можно считать $y\ge2$. Для $y$-гладкого $h\le H^{1/4}$ вероятность того, что гладкая часть точно равна $h$, получается подсчётом кратных $h$ с частным, свободным от простых $\le y$. Нижнее решето размерности один на уровне $H^{1/4}$ даёт
   $$\Pr(h)\ge (1-o(1))\frac1h\prod_{p\le y}(1-1/p)-O(H^{-3/4}).$$
   Действительно, каждый остаток при подсчёте кратных $hd$ имеет абсолютную величину не более единицы, веса решета ограничены единицей, а $\log(H^{1/4})/\log y\to\infty$. Произведение, делённое на $h$, есть точная вероятность в независимой модели. При суммировании по $h\le H^{1/4}$ абсолютная ошибка равна $O(H^{-1/2})$. Модельная вероятность больших $h$ равна $o(1)$ по Маркову: $\mathbb E\log h=\sum_{p\le y}\log p/(p-1)=O(\log(2y))$. Сумма положительных дефицитов вероятностей равна полной вариации. Это доказывает нужное утверждение для любой ограниченной функции профиля. Аналитический вход — Kevin Ford, *Sieve Methods*, Theorem 3.6, https://ford126.web.illinois.edu/sieve2023.pdf .
2. Для $d\le M^{1-\eta}$ длина интервала частных при $d\mid t$ равна $M/d+O(1)$. Поскольку $d$ взаимно просто с малыми простыми, их профиль равен профилю частного. Значит, разность нормированных средних одного члена на $I,J$ равна $o_\eta(1)/d+O(1/M)$. Сумма $1/d$ ограничена абсолютной константой по формуле Мертенса, так как $\sum_{M^{1/4}<p\le M}1/p=\log4+o(1)$ и число множителей не больше трёх. Число этих внутренних модулей не превосходит $M^{1-\eta}$ с точностью до постоянной кратности.
3. Для $M^{1-\eta}<d\le M$ зафиксируем произведение $e$ всех простых, кроме самого большого $q$. Тогда $q$ лежит в пересечении $(M^{1-\eta}/e,M/e]$ и $(M^{1/4},M]$. Отношение верхнего конца к нижнему не превосходит $M^\eta$. По формуле Мертенса сумма $1/q$ по этому интервалу есть $O(\eta)+o(1)$ равномерно по $e$: отношение логарифмов концов не больше $1+4\eta$. Сумма $1/e$ ограничена тем же аргументом, что в пункте 2. Доля кратных каждого $d\le M$ в любом интервале не больше $1/d+1/M\le2/d$. Поэтому весь пограничный вклад есть $O(\eta)+o(1)$. Сначала устремляем $M$ к бесконечности, затем $\eta$ к нулю.

Итак, $E_I F-E_J F=o(1)$, где $E$ — среднее по соответствующему интервалу. Это доказывает сравнение в (1).

Для общего множества $S$ положим $y=\max(\log M,(|S|+1)^2)$. Удалим из цены метки $p\in S$ между $y$ и $M^{1/4}$. Двойственный функционал полного вектора превосходит функционал усечённого не более чем на потерянную исходную нагрузку: целевой штраф монотонен. Эта потеря не больше $M\sum_{p\in S,\,p>y}1/(p-1)=o(M)$, поскольку $|S|\le\sqrt y$ и $y\to\infty$. Получаем $\max\Phi\le2n+o(M)$, а затем теорему по округлению из §2.

**Количественная версия без ядра.** При $S=\varnothing$ тот же вывод даёт $\tau_D\le2n+O(M/\log M)$ с абсолютной константой. Теперь коэффициенты мономов постоянны, и ошибка переноса на каждом модуле не больше единицы в ненормированных суммах. Всего модулей $O(M/\log M)$: при фиксированном произведении $e$ из нуля, одного или двух меньших множителей число вариантов наибольшего простого не превосходит $\pi(M/e)\ll M/(e\log M)$, поскольку непустой диапазон требует $M/e>M^{1/4}$. Сумма $1/e$ ограничена. Цена обрезания повторений в каждой сумме ограничена $O(M^{3/4}+\pi(M))$, а округление даёт ещё $\pi(M)$. В частности эта версия имеет относительный остаток $o(n)$ уже при $n\log M/M\to\infty$.

## 5. Следствие и граница доказательства

Для любого $y=M^{o(1)}$ применим доказанное сравнение к цене после удаления $y<p\le M^{1/4}$. По монотонности целевого штрафа для исходной цены
$$\Phi(w)\le 2n+M\sum_{y<p\le M^{1/4}}\frac{w_p}{p-1}+o(M).$$
Если следствие §1 неверно, можно взять $M_j=3n_j\to\infty$ с нарушением для $c_j=1/j$, $j>4$, и с $\tau>(2+\delta)n_j$. Тогда $y_j=M_j^{1/j}=M_j^{o(1)}$. Округление требует $\Phi(w)\ge\tau-\pi(M_j)>2n_j+(\delta/3-o(1))M_j$. Правая часть предыдущей оценки при нарушении не превосходит $2n_j+(\delta/6+o(1))M_j$. Противоречие.

**Точное препятствие.** На четырёх метках сертификат §3 может нарушать каноническую верхнюю границу. Возьмём $M=11\cdot13\cdot17\cdot19=46189$, $t=M$, нулевое ядро и цены $(1/2,1/2,1/2,1)$. Все предшественники допустимы по условию $p^2q\le M$. Для первых трёх приращения сертификата равны по $1/2$. При $q=19$ на первой половине интервала интегрирования $k=0$, на второй $k=3$. В обоих случаях $P=1$. Получается $F(t)=5/2>\min(X(t),2)=2$. Это опровергает точечный шаг предлагаемого продолжения. Оно не опровергает сравнение средних и не даёт нижней оценки на $g(n)$. Для полного доказательства остаётся оценить одновременно цены промежуточных простых и обеих крайних групп на одном наборе целевых точек.

## 6. Конечная проверка сертификата

Самодостаточный Python 3. Цены и нагрузка ядра заданы в единицах $1/3$. Целые стоимости моделируют $100\log_M p$. При интегрировании проверяется середина каждого отрезка длины $1/3$, поскольку индикаторы постоянны в его внутренности. Вывод фактического запуска — 229376 проверенных комбинаций. Это проверка конечной модели, а не доказательство асимптотики.

~~~python
from itertools import product

costs = (26, 28, 31, 34, 41)
profiles = [tuple(i for i in range(5) if mask >> i & 1) for mask in range(32)]
cases = 0
for weights in product(range(4), repeat=5):
    for core in range(7):
        for present in profiles:
            certificate = min(core, 3)
            for q in present:
                for j in range(weights[q]):
                    twice_u = 5 - 2 * (core + j)
                    if twice_u < 0:
                        continue
                    count = sum(
                        p < q and 2 * costs[p] + costs[q] <= 100
                        and 2 * weights[p] > twice_u for p in present
                    )
                    certificate += 1 - count + count * (count - 1) // 2
            load = core + sum(weights[p] for p in present)
            assert min(load, 3) <= certificate
            if sum(costs[p] for p in present) <= 100:
                assert certificate <= min(load, 6)
            cases += 1
print(cases)
~~~

Статус верификации — письменный вывод; проверка конечной модели в Python; Wolfram Language независимо подтвердил значения квадратичного полинома и арифметику четырёхметочного примера. Формализации Lean нет.
